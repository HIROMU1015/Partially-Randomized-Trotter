# 3. 対象となる部分乱択モデル

## 3.1 Hamiltonian

固定有限次元のHamiltonianを

\[
H=H_D+H_R
\]

とします。

乱択部分は

\[
H_R=\lambda_R\sum_jp_jP_j
\]

と定義します。

ここで、

\[
P_j=P_j^\dagger,\qquad P_j^2=I,
\]

\[
p_j\ge0,\qquad \sum_jp_j=1,
\qquad \lambda_R>0.
\]

初期scopeはPauli／Hermitian involutionに限定します。

一般のHermitian eventやDF fragmentへ勝手に拡張してはいけません。

## 3.2 Exact deterministic half

決定論部分について、

\[
D=e^{i\alpha H_D}
\]

を使用します。

初期T1bでは、決定論blockをexact exponentialとします。

実際のProduct Formulaによる回路実装は対象外です。

ただし、**exactなH_Dの指数関数を使うことと、H_D+H_Rの対称分割誤差がゼロであることは異なります。**

Outer splitting biasは解析対象として保持してください。

## 3.3 Gate共有±と平均写像

乱択gateは

\[
A_j=e^{i\theta P_j}
\]

です。

一step内の乱択wordは

\[
R=A_{j_r}\cdots A_{j_1}
\]

とし、逆順の積を

\[
R^{\mathrm{rev}}=A_{j_1}\cdots A_{j_r}
\]

とします。

正負branchは、同じ時系列の乱択labelを共有し、各gateの符号を反転します。

採択済みの平均写像は、

\[
\boxed{
\Psi(X)
=
D\Phi_\theta^r(DXD)D
}
\]

です。

ここで、

\[
\Phi_\theta(X)
=
\mathbb E_j[A_jXA_j].
\]

この恒等式は、指定されたbranch順序とIID条件の下で既存レビューが確認した出発点です。

**この写像の存在だけで移送保証が成立したとは扱わないでください。**

同符号の二側作用 \(DXD\) を、密度演算子の変換 \(DXD^\dagger\) と混同しないでください。

# 4. 正式採択済みのjoint scaling

T1bでは、S0で正式採択した次の条件を維持してください。

\[
T_{\mathrm{rel}}=s\delta_{\mathrm{rel}}
\]

\[
\theta=
\frac{\lambda_R\delta_{\mathrm{rel}}}{2r}
\]

\[
\alpha=\frac{\delta_{\mathrm{rel}}}{4}
\]

\[
D_{\mathrm{damp}}=sr\theta^2
\le D_{\mathrm{cap}}.
\]

初期研究対象は次の系列です。

- Hamiltonian・分割・sampling lawを固定する。
- \(r\ge1\) は固定の正整数とする。
- \(\delta_{\mathrm{rel}}\to0\) とする。
- \(\theta\to0\) とする。
- \(\alpha\to0\) とする。
- \(s\delta_{\mathrm{rel}}^2\) を有限範囲で管理する。
- 非自明な減衰を調べる際は、\(D_{\mathrm{damp}}\) が正の有限値に近づく系列を対象とする。

固定step幅のまま \(r\to\infty\) とする極限は初期対象に含めません。

系サイズとrを同時に増やす一般的なスケーリング保証も初期対象外です。

**長時間と小stepの極限を混同しないでください。**

また、エネルギーgapによる固有位相の分離はstep幅とともに縮む可能性があります。

小さい摂動と小さいspectral gapの比を必ず考慮してください。

# 5. 最優先の理論検証事項

## T1b-1：一step平均写像の解析的展開

最初に、採択済みのexactな \(\Psi\) を出発点として、一stepの小step展開を導いてください。

区別すべきものは、

1. 理想的な全Hamiltonianによるcoherent生成子
2. 乱択に由来する二次散逸項
3. 決定論部との非可換な交差項
4. 有限stepの位相補正
5. 三次以上の局所剰余

です。

T1aの

\[
\mathcal D
=
-\frac12
\mathbb E(\mathcal J_j-\mathcal L)^2
\]

に相当する構造が、今回どのような正規化係数で現れるかを検証してください。

全Hamiltonianのcoherent生成子と乱択部の散逸項を明確に区別してください。

一stepの形式的Taylor展開だけで長時間保証が得られたとは扱いません。

**必要な局所誤差の次数、norm、係数依存を明示すること。**

## T1b-2：長時間一様な誤差評価

T1aの手法を参考に、今回の部分乱択で長時間一様な評価が成立するか検討してください。

具体的には、

- Hilbert–Schmidt normでの安定性
- 一stepの局所剰余
- 非可換な反復のtelescoping
- Interaction picture
- Secular averaging
- Nonresonant／near-resonant寄与
- Pair-sum resonance
- Spectral gap依存
- 次元依存
- State／mode weight

を対象とします。

評価は採択済みの

\[
s\delta_{\mathrm{rel}}^2=O(1)
\]

という長時間・小step系列について行ってください。

T1aの定数18をそのまま使用せず、T1bの一step写像に対応する剰余を改めて導いてください。

**一般定理が成立しない場合、どの仮定・補題・極限で障害が生じるかを明示してください。**

強い一般定理が得られなくても、自然な仮定の下での有用な十分条件や限定的な定理は成果として認めます。

# 6. 減衰係数と位相補正

## T1b-3：全Hamiltonianの固有状態での評価

対象状態は、

\[
H|k\rangle=E_k|k\rangle
\]

を満たす全Hamiltonianの固有状態とします。

完全乱択の \(h_R\) の固有状態を、全Hの固有状態として扱ってはいけません。

次を検証してください。

1. \(\Psi\) の有効固有mode
2. 左右modeまたは適切な射影の構造
3. 対象状態から有効modeへの変化
4. 長時間の減衰係数
5. 位相補正
6. Spectral weight
7. 近縮退の影響
8. Signal floorがある場合の条件付き位相評価

非正規な平均写像の固有値だけから、実際のcoherent信号の減衰や位相を結論しないでください。

## T1b-4：Dressingの影響

決定論halfによる状態変化の評価と、減衰係数の変化を区別してください。

特に、

- 状態vectorの差
- 有効modeの差
- 減衰係数の絶対誤差
- 減衰係数の相対誤差
- 改善因子ρの誤差

を別々に取り扱ってください。

状態の近さが保証されても、減衰係数の相対誤差が同程度に小さいとは限りません。

小さい分母やゼロ分母の扱いを明示してください。

# 7. 共鳴・aliasing・outer splitting bias

## T1b-5：Spectral resonance

次を区別してください。

- 全Hの固有値gap
- Pair-sum resonance
- 実際に結合するspectral mode
- Sector外の結合
- 有効step固有位相のalias
- 低周波の重み

対象状態の通常のground-state gapが正であることだけで、すべてのpair-sum共鳴が無いと判断しないでください。

保存量で到達可能空間が制限される場合も、その保存性と端点性を個別に確認する必要があります。

## T1b-6：Outer splitting bias

Exact deterministic halfを使っても、

\[
H_D+H_R
\]

の非可換性に由来する対称分割誤差が残ることを考慮してください。

次を分離します。

1. 理想的な全Hのcoherent時間発展
2. 決定論的な対称分割によるbias
3. 乱択による信号の減衰
4. 乱択による位相bias
5. 非可換な交差項

特に、採択した長時間系列でouter splitting biasが累積したとき、乱択の先導次数とどのような関係になるか検討してください。

Outer splitting biasを黙ってQ4へ先送りして、T1bの理論的な比較対象を不明確にしないでください。

# 8. 改善因子ρの科学的判定

## T1b-7：候補式の評価

これまでのレビューでは、完全乱択に関して、

\[
\rho_\infty
=
\frac{V_k+v_{kk}}{2V_k}
\]

という先導係数の比が整理されています。

一方、部分乱択における

\[
\rho_\infty^{(H)}
\]

は未証明です。

今回、部分乱択について、

1. 同様の係数比が成立するか
2. Dressingなどによる補正が必要か
3. 適用条件がどの程度強いか
4. 小分母や共鳴で定義できなくなるか
5. 比較するordinary／独立±の減衰係数が本当に対応しているか

を解析してください。

結果は次のいずれかに分類してください。

- `HOLDS`
- `HOLDS_WITH_CORRECTION`
- `NOT_APPLICABLE`
- `UNRESOLVED`

必要に応じて、明確な数学的反例や不能性を別に報告してください。

**従来のρの候補式を成立させるために、仮定を後から都合よく追加してはいけません。**

もし自然な条件で式が成立しなければ、その結果自体が研究上の重要な情報です。

また、ρの成立はRPEの総資源改善の十分条件ではありません。

# 10. 研究の進め方と技術的なSTOP

T1bの作業は、最初から必ず一般定理を完成させることを目的としません。

推奨する順序は次のとおりです。

1. 正確な一step平均写像と小step展開を確立する。
2. 散逸性・収縮性・局所誤差の構造を調べる。
3. 長時間平均化が成立する条件を導く。
4. 全Hの対象mode・位相・減衰を評価する。
5. Dressing・共鳴・outer biasを整理する。
6. 改善因子ρの成立・修正・不適用を判断する。
7. T1bの結論とCheckpoint 2への引継ぎ資料を作成する。

### 以下の場合はmandatory STOPすること

- 正式S0契約と異なる研究対象が必要になる。
- 重要な数式の成立に説明不能な矛盾が見つかる。
- 一般定理に不可欠な仮定が物理的に極端であると判明する。
- 既知の理論を単に再表示しているだけで、研究上の新しい情報が得られない。
- 減衰係数やρの正当化に不可欠な問題が残る。
- 必要な原資料の取得ができない。
- 保護対象のGitHubファイルに影響する。
- 科学計算を行わなければ解消できない問題が発生する。

ただし、数学的な障害が見つかった場合でも、**承認範囲内の解析的な代替証明・十分条件・反例検討まで直ちに禁止するものではありません。**

Codexで解決可能な技術的問題は、できる限りCodex側で完結してください。

一方、既存契約を変更するほど重要な科学的判断が必要な場合は、根拠を整理して停止してください。
