# 2. 今回正式採択するGate 0の科学的範囲

## 2.1 実験の目的

今回のGate 0は、

**「保存されたH4 Hamiltonianに基づく非冗長Pauli-tailについて、small-stepの先導減衰係数に改善の余地が存在するかを診断する」**

ことを目的とします。

RPE全体の保証、化学的精度の確認、総資源改善、実機回路価格の比較は対象外です。

主評価量は、

\[
W_k=1-\langle k|h^2|k\rangle
\]

\[
v_k=
\operatorname{Var}_j
\langle k|P_j|k\rangle
\]

\[
\rho_\infty^{(H)}
=
\frac{W_k+v_k}{2W_k}
\]

です。

ここで、

\[
h=H_R/\lambda_R.
\]

これらを**oracle headroom診断量**として扱います。

数値的な対象stateが厳密固有状態であることを、今回の正式採択によって認定したわけではありません。

## 2.2 正式採択する入力

- H4 linear 1.00 Å
- STO-3G
- 8 spin orbitals
- DF rank12
- 保存済みdevelopment NPZ
- Charge 0
- Multiplicity 1
- 保存済みN=4、Nα=Nβ=2、Sz=0のsector情報

入力NPZ：

https://github.com/HIROMU1015/Partially-Randomized-Trotter/blob/8b7666d0270f7fac01e430e195bef7b58ac0116c/artifacts/pr2_s0_s1_validation/2026-09-28/h4_1p00_rank12_development_v1.npz

SHA256：

`3bc92e92c595a50eadf97c80ed8641adbb214b14e6e94b7a28ac08e8c2e0f80a`

保存Hamiltonian hash：

`de7a549238e3a21f15a84018bef28440c345b31030282c01cf874f3d1d212424`

既存の凍結DF Hamiltonianを正本とします。

新SCF、積分計算、DF因子の生成、geometry変更、basis変更は禁止します。

H4 1.30 Å、H6、別rankは初回評価へ追加しません。

## 2.3 正式採択する分割

既存のDF block生成順を維持します。

| ID | HD側 | HR側 |
|---|---|---|
| G3 | DF block 0–2 | DF block 3–11 |
| G6 | DF block 0–5 | DF block 6–11 |
| G9 | DF block 0–8 | DF block 9–11 |

Constantとone-bodyはHD側に置きます。

全3分割を結果の成否にかかわらず報告する設計としてください。

後から有利な分割を追加したり、DF blockを重み順に並べ替えたりしてはいけません。

## 2.4 正式採択するPauli law

- Jordan–Wigner変換
- 保存されたspin-orbital順
- 同一Pauli文字列の符号付き係数集約
- 非冗長なcanonical Pauli表
- Identity項をHDへ移動
- Identity移動前後のcontrolled relative phase台帳を保持
- 自動的な小係数cutoffを設けない
- Sampling probabilityを非負で正規化する

Pauli-tailについて、

\[
H_R=\sum_Pc_PP
\]

\[
\lambda_R=\sum_P|c_P|
\]

\[
p_P=\frac{|c_P|}{\lambda_R}
\]

\[
P_{\mathrm{signed}}=\operatorname{sgn}(c_P)P
\]

とします。

\(\lambda_R=0\) の場合は空tailとして分類し、W、v、ρを無理に定義しません。

IdentityをHDへ移すことで乱択lawが変わる点を明示してください。

この採択はDF-nativeの元の乱択eventと同じアルゴリズムであることを認定しません。

## 2.5 正式採択する比較意味論

- 同じ理想Hamiltonian
- 同じD/R分割
- 同じ対象state
- 同じ理想相対時間
- 同じPauli sampling law
- 概念的な総乱択イベント位置数を揃えた比較

比較対象：

- Ordinary
- Independent ±
- Gate-shared ±

ただし、controlled gate価格、native回路深さ、shot数が同じという仮定は置きません。

ρは先導減衰係数に関する診断量です。

# 4. 誤差伝播とρの安定性

Gate 0の中心指標は、

\[
\rho=\frac{W+v}{2W}
\]

です。

従って、Wの数値誤差が小分母により増幅される可能性があります。

## 4.1 必要な誤差会計

少なくとも以下を考慮してください。

- DF入力の数値精度
- Fermionic operatorからPauliへの変換
- Pauli係数の集約
- 虚部を除くことによる誤差
- Identity移動
- Hamiltonian再構成
- 保存stateのnorm
- 保存stateの固有状態残差
- Pauli期待値
- W
- v
- ρ

数値的な誤差区間は、根拠付きのengineering error budgetとして扱ってください。

厳密な数学的certificateや真の固有状態に対する信頼区間と誤認しないでください。

## 4.2 Wが小さい場合

以下を区別してください。

- \(\lambda_R=0\)：空tail
- 浮動小数点でW=0
- Wの不確定区間が0を含む
- Wが正だが非常に小さい
- ρの不確かさが大きい

Wの値を都合よくclampしてρを出さないでください。

適用外の場合は、

- `NOT_APPLICABLE`
- `UNDETERMINED`
- `PRECISION_UNRESOLVED`

など、意味が区別できるclassificationを採用してください。

## 4.3 誤差伝播の具体化

既存SOURCEにあるW、vのengineering区間からρの区間を作る方法について、数学的整合性と前提を技術的に確認してください。

特に、

\[
0\le v\le W\le1
\]

という理論的範囲との関係を確認してください。

ただし、理論的範囲へ数値を無条件に丸め込んで不一致を隠してはいけません。

**SOURCEの数値計算を実行せず、数式・演算構造に基づいて評価してください。**

# 5. State精度と理論適用域

保存NPZにはfull Fock長256のstateが存在します。

ただし、これは保存されたsector-groundの数値参照であり、全Fock空間の厳密な非縮退固有状態だと認定されたわけではありません。

次を区別してください。

1. State normalization
2. 固定Hamiltonianに対するRayleigh残差
3. Sector stateとの埋込み整合
4. 数値的固有状態としての精度
5. Exact eigenstateとの距離
6. 全Hにおける非縮退性
7. 全空間における端点性
8. Pair-sum条件
9. Jensen floorの適用条件

**小さい固有状態残差だけで、gapを仮定せず厳密固有状態との近さを保証しないでください。**

今回のGate 0では、保存stateをoracle診断に用いる方針を採択しました。

そのため、結果は

`NUMERICAL_SECTOR_GROUND_ORACLE_NOT_THEOREM_CERTIFIED`

のように、数値診断と定理適用の認証を区別して報告する必要があります。

科学的に必要な追加の固有値・gap計算が判明した場合も、今回は実施せず別途承認事項として整理してください。
