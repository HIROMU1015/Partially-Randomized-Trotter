## 2. 研究目的

前回のRustiq限定検証では、固定4-mode合成Hamiltonianの4caseで全正しさgateがPASSし、SSの3caseでRZ・CX・depthの削減が確認されました。

既存の設計した8 wrapperの無重み合計は、B0/B1に対してR1が次の結果でした。

- RZ：800 → 780
- CX：402 → 382
- Total depth：988 → 948

これらは固定case集合の1-shot回路資源であり、law重み付き期待値や全round総資源ではありません。

今回の目的は、**この改善が単純な同一Pauli controlled rotationの角度結合によって再現できるかを判定すること**です。

新規実行するB2は、元run・basis・phaseを保持したまま、合法的に隣接する同一Pauli回転を`math.fsum`で結合する方式です。

比較対象には保存済みB0/B1/R1を使用し、新しいRustiq合成は行いません。

## 5. B2限定科学実行

契約`C4_B2_SAVED_COMPARISON_V1`の実行順序とcall数を正本として進めてください。

### Phase A：保存入力・reference復元

- 固定4caseのsaved motif/lawを復元
- 元event、occurrence、signed angle、basis/run/phaseを照合
- 保存128桁reference bundle 14件を復元
- 旧90/128桁の検証済み資格とhashを再利用
- 保存結合前literal NPY 10件を使用

新しいCAR/exterior reference、law、Hamiltonianは生成しないでください。

128桁referenceの復元では、実数・虚数の十進文字列を高精度contextへ直接渡してください。

不明形式の推測補完、`eval`、高精度復元前のbinary64変換は禁止します。

復元失敗や非有限値があればSTOPしてください。

### Phase B：局所operator同値性

対象10領域でB2をbuildしてください。

結合後の各局所operatorを、

1. 保存独立reference
2. 保存された結合前literal operator

の両方と比較してください。

Control=0枝の恒等作用、control=1枝の完全なoperator、unitarityを確認してください。

Global phaseを無視した同値判定やphase fittingは禁止します。

### Phase C：Full controlled evolution

固定4caseについてB2のfull evolutionをbuildしてください。

以下を含む完全な`diag(I,U)`を独立targetと比較してください。

- 元Gaussian basis
- D境界融合
- Taylor phase
- Product sign
- Identity/scalar相対位相
- 元の非可換演算子順序

### Phase D：Actual adjoint・X/Y signal

完成したB2回路から既存方式でactual inverseを構築してください。

独立referenceとの絶対operator比較を行い、さらにfull Hadamard wrapperのX/Y両axisを検証してください。

State preparationとreadoutを既存scopeから変更しないでください。

### Phase E：Compiled正しさ

Phase B～DがPASSした後、同一compiler profileでfull-wrapperをcompileしてください。

Compile後にも、

- 完全なwrapper operator
- X/Y複素信号
- 相対位相
- 測定を含む回路scope

を検証してください。

Compiler cacheはB2専用とし、cold8 miss・warm8 hit、warm追加transpile0を確認してください。

### Phase F：回路資源比較

**全4case・両axisの正しさgateがPASSした場合のみ**資源比較へ進んでください。

B2のcompiled full-wrapperについて、既存の`circuit_metrics`を再利用して以下を取得してください。

- RZ count
- CX count
- RZ depth
- CX depth
- Total depth
- Quantum-only depth
- Circuit size
- Measurement count

B0/B1/R1は保存結果を再利用してください。

B2と保存B1/R1を同じcase・axisで対応付けて比較し、結果を保存してください。

保存B1 raw QPYと新B2 raw回路の診断も、固定契約の範囲で実施してください。

新しいlaw重み付き集計、認証shot数、全round総資源、T count推定は行わないでください。

## 7. 比較結果の解釈

固定4caseの全正しさgateがPASSした後、設計正本のGO／STOP条件に従って結果を整理してください。

特に、以下を区別してください。

**A. B2がR1の削減を再現した場合**

単純角度結合が今回の観測改善を説明できることを支持します。

ただしRustiq内部の機構が一意に同定されたとは主張しないでください。

**B. R1がB2より低コストの場合**

単純角度結合で説明できない追加のcompiled費用差が残ったことを報告してください。

これだけでRustiq固有の新規アルゴリズムの優位性を認定しないでください。

**C. B2がR1より低コストの場合**

既知の単純結合が今回のscopeでより有利だったことを報告してください。

**D. Mixed/trade-offの場合**

単一指標だけで勝者を決めず、case・axis・metric別の差を示してください。

有利なcaseだけを抽出して全体優位としないでください。

独立新規性、分子一般、PR同精度総資源について、今回の結果だけで科学的なGOを認定しないでください。

研究Cの継続・終了の正式判断はユーザー・研究C・統括に戻してください。
