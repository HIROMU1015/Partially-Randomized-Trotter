## 3. 作業A：既知手法との同値性・方法差の徹底監査

最優先で実施してください。

次の手法について、一次論文、数学的定義、回路構成、既存sourceを突き合わせてください。

- THRIFTのmixed propagatorとinteraction-picture実装
- occupation条件付きSU(2)回転および可解Hamiltonian
- fermionic single/double excitationの既存実装
- reversible arithmeticによる関数計算と可変角回転
- DF-native PFと、既存のGaussian basis変換・diagonal interaction実装
- その他、今回の構成と直接重複する既知手法

特に以下を調べてください。

1. 今回のconstructorは、既知手法の直接的な組合せ・特殊化・回路最適化に帰着するか。
2. occupation差分を全枝列挙せず計算する方法は、既存手法でも同等に実現できるか。
3. 相対時間発展を直接生成することで、既存の強い実装では得られない構造上の利点があるか。
4. detuningの共通近似による相殺・誤差抑制は、既知の構成にも同様に適用できるか。
5. 既存手法と数学的に同値であっても、回路生成手順、古典前処理、補助qubit、精度設計、計算量などで独立したアルゴリズム上の差が残るか。

**既知のSU(2)回転・可逆算術を組み合わせただけの構成を、自動的に新規アルゴリズムと認定しないでください。**

一方、数学的な同値性だけを理由に、実装アルゴリズム上の非自明な改善可能性を否定することも避けてください。

各論点について、既知手法との対応表を作り、次を明記してください。

- 共通する部分
- 異なる部分
- 差が成立する前提
- 一次資料・source上の根拠
- 未確認事項
- 新規性の候補として残るか、それとも既知手順に還元されるか

未取得の重要な原典がある場合は、可能な限り取得を試み、取得できなければ未確認として扱ってください。

## 4. 作業B：回路構成と具体的資源費用の検討

作業Aを踏まえ、追加投資に値する方法差が存在する可能性を確認できた場合、その実装費用を詳しく検討してください。

対象：

- occupation依存detuningのcompute/uncompute
- fermionic parity
- single/double excitationのpair encoding
- valid flagとcoherent control
- 可逆加算・乗算・除算・平方根
- `atan2`・`hypot`に相当する関数評価
- 可変角回転
- ancilla-relative phase
- 作業レジスタのclean uncompute
- QPEで必要なcontrolled evolution

既存の実装可能なprimitiveを積極的に調査し、既知の可逆算術回路・関数評価回路を再利用できる部分を特定してください。

**この段階では、sqrt・division・Horner等の本格的な量子回路backendを新規実装する必要はありません。**

まずは、既存の技術を使った場合の具体的な回路構成と資源会計を明らかにしてください。

評価項目：

- Toffoli数
- T count
- RZ数
- CX数
- 回路深さ
- 補助qubit数
- 必要な固定小数点精度
- 古典前処理・係数アクセス費用
- 誤差保証とその取得費用

実際の定数が不明な場合は、根拠のある上界・条件付き見積り・未確定値を分けてください。

**未実装の演算を費用0としたり、漸近計算量だけから具体的な量子資源優位を主張したりしないでください。**

具体的なゲート費用が得られない部分は `UNKNOWN` として維持し、何を確認すれば閉じられるかを示してください。

## 5. 作業C：強い既存手法との公平な比較

以下を比較対象としてください。

1. 通常のfermionic excitationベースPF
2. 対称2次PFなどの既知の強いPF
3. 既知のTHRIFT実装
4. 条件付きSU(2)＋可逆算術を用いる強いcompressed実装
5. DF-native PF

新構成だけにgroup化、相殺、係数圧縮、回転共有、精度最適化などの利点を与えないでください。

比較対象にも、同じHamiltonian情報と合理的な実装最適化を許してください。

次の違いを明確にしてください。

- 一つのmixed propagatorの実装費用
- 一つのtime stepの全費用
- 同じ時間発展精度に必要なstep数
- 基底エネルギー精度に到達するための費用
- 状態準備・測定・制御・normalizationなどの未評価費用

現時点で計算できない項目は、無理に推定値へ置き換えないでください。

## 6. 作業D：改善成立条件・break-even条件の明確化

今回の構成について、既存PF・THRIFT・DF-native実装より有利になり得る条件を、可能な限り具体的に整理してください。

特に、

- 励起数とHamiltonianの疎性
- occupation依存detuningの計算量
- 算術精度と関数評価費用
- mixed propagatorの実装単価
- 相互作用の強さ
- THRIFTまたはPFのstep数減少
- controlled evolutionの追加費用

を考慮してください。

単なる「近可積分なら有利」という説明ではなく、**どの費用がどれだけ減少すれば、追加した算術・制御費用を回収できるか**を式や条件として示してください。

さらに、その条件が量子化学Hamiltonianの構造と整合するかを、既存資料・既知理論の範囲で検討してください。

新しい分子係数生成や数値実験を行わなければ判断できない場合は、その境界を明記してください。

## 7. 作業の優先順位と停止条件

次の順番で進めてください。

**Phase 1：既知手法との同値性・方法差の確認**

これを最優先とします。

**Phase 2：方法差が残る場合の実装構成・費用境界の具体化**

強い既存実装にも同じ最適化を与えて比較してください。

**Phase 3：改善成立条件と、必要なら最小pilotの設計**

研究判断を変えるために必要な情報を整理してください。

Phase 1で既知手順への還元が明確になり、独立した構成上・費用上の差も見つからなければ、**詳細な関数回路実装や大規模な検証に進まないでください。**

その場合も、何が既知手法と同じで、何が未確定なのかを技術資料として整理してください。

方法差が残る場合でも、それだけで科学的GOを出さず、GPT判断資料を作成してください。
