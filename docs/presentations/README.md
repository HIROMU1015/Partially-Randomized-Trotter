# 発表資料

発表資料とスライド生成用の構成案は、研究内容を説明するための二次資料であり、研究方針や
数値結果の正本ではない。内容を更新するときは
[`../research/研究概要・現状.md`](../research/研究概要・現状.md)と個別の検証文書を参照する。

現在、次の構成案は互換性維持のためリポジトリ直下に置いている。

- [`../../BentoSlide構成案.md`](../../BentoSlide構成案.md)：研究方針全体の資料構成案
- [`../../BentoSlide構成案_回路コスト検証.md`](../../BentoSlide構成案_回路コスト検証.md)：回路コスト検証の続編構成案

既存の研究紹介PDFは[`../research/DF+PRコスト評価.pdf`](../research/DF+PRコスト評価.pdf)である。
その続編として作成した回路コスト検証スライドは
[`../../current-bentoslide.pdf`](../../current-bentoslide.pdf)である。いずれも作成時点の説明資料であり、
最新の数値と判断は研究概要・検証文書・machine-readable artifactを優先する。
`.bento-html-change-*.candidate.html` は資料生成時の一時候補であり、Git管理対象外とする。
