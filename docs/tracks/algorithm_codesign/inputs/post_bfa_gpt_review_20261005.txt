# 2. 新規性を調べ直した結果

## 2.1 項ごとに実行頻度を変える方法は、既にある

Poulinらの *The Trotter Step Size Required for Accurate Quantum Simulation of Quantum Chemistry* は、§VIで **coalescing** を扱っています。異なるHamiltonian項を異なる間隔で実行する構成で、Eq. (26)に具体例があります。さらに、単に係数の大小で頻度を決めるだけでは十分でなかったことと、別の重要度規則も述べています。:chatgpt-content-reference{index="5"}

特に重要なのは、同論文が**sum-of-squares分解とcoalescingの組合せも試し、その検討では改善が得られなかった**と記載していることです。これは今回のDF構成を否定する結果ではありませんが、「DFへmultirateを導入する発想には直接の先行例がない」とは説明できません。:chatgpt-content-reference{index="6"}

したがって、

> 大きい項を頻繁に、小さい項を低頻度に実行する。

という一般構想を研究Bの新規性にはしません。

## 2.2 「高精度群・低精度群・ランダム残差」の三層構造も、重複が強い

SPRINTのFig. 1には、

\[
H=H_A+H_B+H_C
\]

と分け、dominant群へ高次PF、別群へ低次PF、小さい残差へqDRIFT／RTE等を配する構造が明示されています。processingや実装費用も含む設計です。:chatgpt-content-reference{index="7"}

**次数を変えることと実行頻度を変えることは完全に同じではありません。** それでも、「異なる群へ異なるsimulation手法を割り当てる」という上位の共同設計思想は既知です。

Composite Quantum Simulationsも、coalescingを背景にTrotterとqDRIFTを組み合わせるpartitionを扱っています。ただし主な保証対象はchannelなので、今回のcoherent signalへ保証をそのまま移せるとはしません。:chatgpt-content-reference{index="8"}

## 2.3 「commutatorを使って安く誤差を評価する」だけでも、新しくない

今回、比較へ追加すべきと判断した重要な文献が、Maxwellらの *Practical Estimation of Trotter Error for Hamiltonian Simulation* です。

同論文は、BCH展開のcompactな表現、commutatorのgrouping、重要な寄与の抽出、古典的な状態表現を使う評価を提案しています。特に§III.B–Cと§IV.Aが、次の研究Bに近い比較対象です。:chatgpt-content-reference{index="9"}

したがって、次の三つだけでは独立した方法上の差になりません。

> commutatorで重要度を付けた。  
> errorとcostを同時に考えた。  
> 安い評価から良い設定を選んだ。

ここは、過去R3で「一般optimizerの適用を超える具体的な差」を固定できなかった問題とも一致します。

### 新規性についての現時点の判断

| 主張候補 | 判断 |
|---|---|
| fragmentごとにTrotter刻みを変える | 既知 |
| 複数の決定論群とランダム残差を組み合わせる | 一般構想の重複が強い |

**現時点で「新しい方法が成立した」と認定できるものはありません。** 一方、次に何を作れば既知研究との差を判定できるかは、かなり具体化できます。

# 5. 数学的に、まず何を切り分けるべきか

ここからは、**今回の計画を具体化するための導出**です。新しい理論成果や、分子で実証された結果として提示するものではありません。

## 5.1 内部を細かくして減る誤差と、群間に残る誤差は別

二群

\[
H=A+B
\]

を考えます。\(A\)のnative symmetric PFを\(S_A(u)\)とし、

\[
\log S_A(u)
=
-iuA+u^3K_A+O(u^5)
\]

と書きます。

説明用に\(B\)のexponentialをexactとして、

\[
V_m(h)
=
e^{-ihB/2}
\left[S_A(h/m)\right]^m
e^{-ihB/2}
\]

を考えると、固定\(m\)、十分小さい\(h\)に対して、

\[
\log V_m(h)
=
-ih(A+B)
+
h^3\left(
K_{\mathrm{cut}}+\frac{K_A}{m^2}
\right)
+
O(h^5)
\]

となります。

ここで\(K_{\mathrm{cut}}\)は、\(A/B\)の分割に由来する項です。

**重要なのは、\(m\)を増やしても\(K_{\mathrm{cut}}\)は一般に消えないことです。**

つまり、

> 大きいHamiltonian部分を細かく実行すればよい。

ではありません。

必要なのは、

> **細分化で減らせる内部誤差が大きく、群間に残る分割誤差が相対的に小さいか。**

という判断です。

また、\(A\)が一つのexactに実装可能なgeneratorなら、

\[
[e^{-ihA/m}]^m=e^{-ihA}
\]

なので、細分化しても内部誤差を減らす自由度はありません。無意味な反復を増やさないことが、最初のcontrolになります。

## 5.2 費用と合わせると、検証すべき条件が具体化する

設計用のleading評価を、

\[
E_{\mathrm{model}}
\simeq
\frac{T^3}{q^2}
\left(
\chi_{\mathrm{floor}}
+
\frac{\chi_{\mathrm{fine}}}{m^2}
\right)
\]

と書き、1 macro-stepの費用を、

\[
mc_f+c_c
\]

と近似します。

ここで、shotとtail費用の変化をいったん固定し、\(q\)を連続変数として除くと、費用の\(m\)依存は、

\[
f(m)
=
(mc_f+c_c)
\sqrt{
\chi_{\mathrm{floor}}
+
\frac{\chi_{\mathrm{fine}}}{m^2}
}
\]

です。定数が正なら、その停留点は、

\[
\boxed{
m_*^3
=
\frac{c_c\chi_{\mathrm{fine}}}
{c_f\chi_{\mathrm{floor}}}
}
\]

となります。

この式は新規性として主張しません。**最初のpilotが何を調べるべきかを明確にする診断**です。

ここから、少なくとも、

- 低頻度へ移したい群が実装上高価である。
- 高頻度群の内部誤差が、細分化で減らせる。
- 群間に残る誤差が、その利益を打ち消さない。

という条件が関係します。

ただし、\(\chi_{\mathrm{floor}}\)は**評価式に残る項であって、実際の誤差の下界ではありません**。誤差相殺や高次項があるため、これを物理的な精度限界と呼んではいけません。整数\(q\ge1\)、actual fusion、RTE normalization、shot数を戻すと、実際の選択も変わり得ます。

# 6. DF固有の部分を、どこに作るか

## 6.1 小さい一粒子行列から評価を始める

DF fragmentを、実際の保存規約に合わせて、

\[
D_\ell=\lambda_\ell F(G_\ell)^2,
\qquad
F(G)=\sum_{pq}G_{pq}a_p^\dagger a_q
\]

と表します。

fermionic bilinearには、

\[
[F(G_i),F(G_j)]
=
F([G_i,G_j])
\]

という恒等式があります。

固定粒子数\(N\)のsectorで、

\[
\|F(G)\|\le N\|G\|
\]

を使うと、例えば、

\[
\|[D_i,D_j]\|
\le
4|\lambda_i\lambda_j|N^3
\|G_i\|\|G_j\|
\|[G_i,G_j]\|
\]

という粗い評価を得られます。

これも初等的な出発点であり、**この式だけを新しい成果にはしません。**

価値が生じる可能性があるのは、many-body matrixを作らずに、DF小行列から、

> どの群内部の誤差を減らすべきか。  
> どのgroup間の分割は粗くできないか。

を、既知の一般評価より有用に判定できる場合です。

## 6.2 pairwise normだけで終わらせない

二次PFの誤差ではnested commutatorが必要になります。そのため、単に\(\|[G_i,G_j]\|\)を並べるだけでは、十分な判断量にならない可能性があります。

次の技術的な到達目標は、

> **頻度を変更したときに増減する誤差項を特定し、その組合せを保ってDF小行列から評価すること。**

です。

ここで、一般のBCH groupingや既存partition-error評価と比べて、

- 計算量が小さい。
- より少ない情報で役立つ。
- 同じ情報・予算でも有用な実行列を作れる。
- boundや診断が過度に保守的にならない。

のどれを実際に改善するかを明示します。Maxwellらの方法は、この比較から外せません。:chatgpt-content-reference{index="14"}

また、sector normを使うなら、入力状態だけでなく**全primitiveとsampled operationがそのsectorを保つこと**も確認する必要があります。

## 6.3 回路費用を、action数だけへ戻さない

実行頻度を下げても、basis遷移や融合機会が変われば、回路費用の削減が想定どおり残るとは限りません。

したがって初期段階の解析的countはproxyとして使い、最終候補では、

\[
G_{\mathrm{compiled}}
=
\sum_a
N_a\,
\mathbb E[C_a^{\mathrm{compiled}}]
\]

で評価します。

現行実装には、basis変換を無制御にし、diagonal primitiveを制御する構成や、同一blockの境界融合が既に入っています。**存在しない非効率をbaselineへ仮定して改善を作ってはいけません。**

# 7. 最初に扱うalgorithmの範囲

初期段階では、

\[
H=A+B+R
\]

とし、**ランダム残差\(R\)の物理splitとfinite-RTE法は固定**します。

変更するのは、deterministic側の二群と、その相対実行頻度です。再factorization、高次PF係数探索、新しいimportance sampling、BLISS等を同時に入れません。これは新しい研究全体を永久に制限するものではなく、最初の寄与を切り分けるための提案です。

実装では、\(A/B\)の和のexponentialを無料のexact oracleに置き換えず、native DF primitivesへ展開します。詳細計画書には、\(A\)内部の対称PFと\(B\)のforward/reverse sweepを使う構成案を示しました。

ここで重要な比較が二つあります。

**一つは、同じnested構成の\(m=1\)。**  
これにより、rateを変える効果を見ます。

**もう一つは、元のflat S2。**  
これにより、そもそもnested構成を採用する価値があるかを見ます。

この二つを分けないと、過去P-Dと同様に、内部構成の追加workが大きいことを見落とす危険があります。P-Dのnested／native差は大きいaction proxy差でしたが、当時もそのままcompiled優位性とは解釈していません。

また、有限化前のexact exponential融合と、有限化後のsampled circuitの同値変形は分離します。

\[
P_K(A)P_K(B)\neq P_K(A+B)
\]

なので、有限RTE blockの時間を足す操作を、単なるcompiler最適化とは扱いません。

| 群間誤差が支配 | 内部を簡単に、\(A/B\)の非可換性を強くする | \(m\)増加では解決しないことを捉える |
| normを保った構造変更 | 固有値を保ち相対basisを変える | normだけで区別できない選択に情報が効くか |

単一粒子とinvolutionだけを使って、\(F(G)^2\)がidentityへ退化するtoyでは、DFの非自明な構造を調べられません。modelの作り方自体も、実験前の確認対象です。

また、**提案法が良く見えるmodelだけを採用しません。** 可換control、群間誤差が支配する失敗例、既知対照と同じになる例を含めて保存します。

## 8.3 実回路へ進める条件

BM-1で、単なる既知のnorm-based coalescingでは説明し切れない差が残った場合に、development実装へ進みます。

ここで最低限必要な対照は、

- current flat S2＋finite RTE。
- 同じnested構成の\(m=1\)。
- norm-based／一般commutator-based設計。
- 適用可能な既知near-integrable構成。

です。

すべてを最初のtoyへ詰め込む必要はありませんが、**最終的なclaimに必要な対照を、勝敗を見てから都合よく外してはいけません。**

SPRINT全体の再実装を最初の完成条件にはしません。適用する構成を特定し、同じtask・primitive・精度・control phase・費用指標へそろえて比較します。

# 9. 新規性として、何ができれば十分か

ここは二つの成立形を残すのがよいです。

## 9.1 方法としての成立

目標は、

> **DF入力から計算可能な構造量を用いて、実行頻度変更の追加誤差と実装削減を評価する手順を構成し、その手順が作る回路に、既知の同情報対照を超える有用性を示す。**

です。

必要なのは、単に違うscheduleを出すことではありません。

**入力情報、計算手順、古典費用、誤差の扱い、実装、対照、適用範囲が閉じていること**が必要です。

新しい厳密定理は唯一の道ではありません。実行可能な新しい構成と、十分に切り分けられた実証でも成立し得ます。ただしheuristicなら、それをcertificateへ言い換えず、独立評価で支えます。

## 9.2 適用・実装研究としての成立

具体化した結果、方法の主要部分が既知coalescing／SPRINTの適用にとどまる可能性もあります。

その場合でも、

> **DF-native実装ではどの条件で利益が残り、どの条件で消えるかを、比較可能なデータと機構で示す。**

という成果は考えられます。

ただし、これは研究Aと内容が重ならないようにする必要があります。

- 研究A：**方式を固定した資源競争と適用条件。**
- 研究B：**実行列を変更する構成と、その有効・不利条件。**

同じH4のwinner表をもう一枚増やすだけなら、独立した二本目としては弱いです。

# 10. 論文としての着地点

| 着地点 | 最低限必要な内容 | 現時点の位置 |
|---|---|---|
| **B-Fの研究記録** | 限定BF-A、元INCONCLUSIVEとの区別、再現可能な復元記録 | ほぼ材料がそろっている |
| **B-Mの限定構成・適用研究** | 具体的な実行列、強い対照、誤差・costの機構、有効／不利領域 | 未実証。これから構成する |
| **B-Mの方法論文** | DF固有の評価／構成手順、取得情報と古典計算量、actual資源差、未使用条件 | 推奨する目標 |
| **広い発展研究** | 可証な改善域、構造・系サイズ依存、幅広い化学系、energy推定接続 | 最初の完成条件にはしない |

**B-FのBF-A一件だけを、必ず独立論文にする必要はありません。** 内部ノートや補足として正確に閉じることも適切です。

B-Mについても、結果がnegativeなら自動的に“negative-result paper”になるわけではありません。論文として残すには、例えば、既存実用法の前提が破れる範囲や、明示した構成classの限界など、**他の研究者が利用できる非自明な知見**が必要です。

逆に、そのような知見が得られれば、常に提案法が勝たなくても研究は成立し得ます。

# 11. 他候補の優先順位

B-Mを第一候補にする理由は、現在のDF・PF・controlled実装基盤との接続が明確で、具体的な反証試験へ落としやすいからです。**新規性や性能が最も高いと確認されたからではありません。**

| 候補 | 今回の扱い |
|---|---|
| B-Fの精度／family追加 | 現行主仮説を閉じる。別の機構なしには延長しない |
| B-Sの本格sampler開発 | 現保存標本のheadroomを理由に、当面保留 |
| 単純な三層multirate化 | これ自体を新手法として採用しない |
| **DF構造に基づく頻度削減構成** | **次に構成可能性を調べる第一候補** |
| THRIFT／interaction picture | 必要な部分Hamiltonianを安く実装する具体案がある場合に検討 |
| Trotter誤差のLCU補償 | 既知補償法との差が具体化した場合のみ |
| MPF等への差し替え | 候補を順番に試すのでなく、別の明確な機構が必要 |

THRIFTには、必要な参照部分の時間発展を効率よく実装できることが重要です。複数DF fragmentの和を、そのまま安いexact solverとして扱うことはできません。Trotter誤差補償にも既知のLCU手法があります。どちらも「別algorithmを入れた」だけで新規性を認定しません。:chatgpt-content-reference{index="17"}

# 12. 継続・停止判断の考え方も修正する

今後は、**過去の5%や10%を、新しい研究へ機械的に流用しない**方がよいです。

新しい比較では、その段階でのcost model、不確かさ、主張したい効果に応じて、実行前にmaterialityを定めます。action proxyの差とactual compiled差は別です。

継続の根拠は、正しい構成が作れ、既知対照へ同等の機会を与えても、説明可能で再利用可能な利益が残ることです。

一方、次の場合には縮小または終了します。

- 具体的な差分が、既知法の直接適用だけに還元される。
- 頻度削減の利益が、nested overheadやbasis遷移、shot増加で消える。
- 毎回exact signalで調整しないと動かないのに、利用可能情報だけのmethodを主張したい状態になる。
- 結果後に条件を何度も足さないと利得を作れない。

ただし、**有限pilotで差が出ないことを、全域での不可能性へ昇格させません。** また、「新しい定理が完成するまで小型試験を禁止する」という運用にもする必要はありません。

既知との重複を確認し、具体的な技術仮説が書けたら、小型の反証試験へ進む。その結果で、続ける価値を判断する構成です。

# 最終的な進め方

今の段階で推奨する順序は、

\[
\boxed{
\text{B-Fを限定negativeとして閉じる}
\rightarrow
\text{B-Mの具体的な構成・評価法を定義}
\rightarrow
\text{既知対照と小型controlで判別}
\rightarrow
\text{利益が残る場合だけ実回路・独立条件へ}
}
\]

です。

**研究Aは現在の原稿scopeで進め、研究Bの成功をAの完成条件にはしません。** 一方、Bでは、Aの資源会計と実装基盤を再利用しながらも、Aの既知条件を新しいblind evidenceとして扱いません。

今回の再設計で最も重要な変更は、次の点です。

> **「BF-Aだったから、次はmultirateを試す」ではなく、既知multirateでは解決済みの部分を除き、DF構造から“どの頻度変更を採用できるか”を具体的に評価・構成する研究へ進む。**

これが、現時点で研究Bを再出発させる最も筋の通った形だと考えます。ただし、新規性のリスクは依然として高めです。**次に必要なのは新しい名前や大きいgridではなく、既知法と比較できる具体的な技術差を作ること**です。

詳細計画書には、BM-0でCodexへ反映する範囲、情報境界、model設計、baseline、論文構成案まで収録しています。今回、新しい科学計算やリポジトリ変更は行っていません。
