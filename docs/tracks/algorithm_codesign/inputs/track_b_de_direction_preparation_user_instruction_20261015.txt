# Codexへの研究指示：Track Bの研究整理と次期アルゴリズム改善方向の検討準備

## 0. 今回の基本方針

これまでTrack Bでは、Return aggregation、Parent allocation、importance sampling（IS）、native回路費用の最適化など、複数のアルゴリズム改善を検討してきた。

直近ではParent allocation S4までの科学計算と独立レビューを完了した。

その結果を踏まえ、ユーザーは次の**D＋E方針を正式に採択した**。

- **D：Parent allocationを限定的成果として整理する。**
- **E：Parent allocationの現在の数値探索をいったん区切り、次のアルゴリズム改善方向へ研究資源を移す。**

ただし、Parent allocation一般の不可能性を認定したわけではなく、永久的な研究終了でもない。

今後、新しい理論的発見や実用的な適用条件が確認された場合には再検討できる。

今回の目的は、Parent allocationをさらに最適化することではない。

**過去のTrack B研究から得られた知見と限界を整理し、次に研究する価値のあるアルゴリズム改善方向をGPTが判断できる状態にすること**である。

今回の作業はCodexで完結させ、技術的な資料収集や整理の途中で細かくGPTレビューを要求しないこと。

ただし、新しい重要な科学的判断はCodexが独断で確定しない。

## 2. 作業A：Parent allocation研究の成果と限界を整理する

Parent allocationについて、これまでの研究結果を最終的な研究記録として整理する。

### A1. 数学的な成果

次を整理する。

- 任意のparent係数配分による平均演算子保存
- common-angle配分のL1正規化最小性
- child-specific allocationによる回転角・係数の変化
- 固定価格proxyとKKT配分
- 訂正KKTの数学的意味
- cost-aware ISとの関係
- 既知Euler pairing、SPS、SCU/CTSなどの先行研究との対応

既知理論の直接帰結と、具体的な実装上の差分を明確に区別する。

### A2. 数値的な成果

S4の訂正済み70 lawを正本として、以下を整理する。

- ordinaryとclosed P5の比較
- 頂点配分＋ISによる条件付きT費用削減
- 約14%／19%という改善率の成立条件
- N、CX、native1Q、bias、係数質量との交換関係
- 訂正KKT／halfwayの結果とその限界
- native回転合成価格への依存
- 準備・読出し費用hへの依存
- 多step化に関する既存の理論的検討

特に、以下を混同しない。

1. 保存結果として確認された数値差
2. 数学的に導出された性質
3. 特定の費用モデルに依存する結果
4. 他の入力へ一般化できる可能性
5. まだ検証されていない仮説

### A3. 研究としての位置付け

今回採択したD＋E方針に沿い、次を明確に記録する。

- どの成果を保持するか
- 現在の方法では何が改善できなかったか
- どの問題が既知手法との重複に当たるか
- 現在の追加探索を区切る理由
- 将来どのような新証拠があれば再開を検討するか

Parent allocation全般について、証拠のないno-goや一般的な性能negativeを宣言しない。

また、旧KKTの不一致、技術的停止、科学的な性能評価を混同しない。

**重要：既存の結果、旧closure、source、authorization、marker、STOPを変更しない。新しい研究記録を追加する形で整理する。**

## 3. 作業B：Track B全体の既存研究を横断的に整理する

次のアルゴリズム改善方向を考えるため、Parent allocationに限定せず、これまでのTrack Bの主要研究系列を確認する。

対象は、リポジトリに実在する固定資料に基づいて特定すること。

少なくとも、関連資料が存在する場合は以下を確認する。

- Return aggregation：G6〜G10など
- RTE／Parent allocation／importance sampling関連
- D1〜D3の資源評価
- R1／R1.5関連
- Synthesis Placement（SP）
- BF／BMのアルゴリズム設計検討
- DF correction関連
- Gaussian構成、時間相関などの過去の候補
- その他、次のアルゴリズム改善の判断に重要な研究系列

全リポジトリを一から再監査する必要はない。

まず既存の研究記録・結果・closure・Decision Packetを確認し、科学的な方向選定に影響する重要資料へ調査を絞ること。

### B1. 各研究で整理する項目

各研究について、少なくとも以下を整理する。

| 項目 | 内容 |
|---|---|
| 研究課題 | 何を改善しようとしたか |
| アルゴリズム上の変更 | 回路・sampling・分解・係数など何を変えたか |
| 数学的根拠 | 恒等式、誤差保証、最適化条件など |
| 比較対象 | 何をbaselineとしたか |
| 検証条件 | 入力、精度、時間、step数など |
| 結果 | 確認されたpositive／negative／inconclusive |
| 資源 | T、RZ、CX、depth、N、古典費用など |
| 限界 | 成立条件、適用範囲、未取得証拠 |
| 既知性 | 既知手法との関係 |
| 今後の示唆 | 新しい研究の設計に役立つ事実 |

単に「成功した研究」「失敗した研究」と二分しない。

例えば、数学的同値性、特定条件での資源不利、実装上の未完了、先行研究との重複は、それぞれ異なる意味を持つ。

### B2. 異なる研究の比較可能性

特に以下を区別する。

- 同一物理targetか
- 有限多項式の近似か、時間発展演算子か、固有値誤差か
- 精度・confidence・biasの意味が同じか
- native資源の単位と計測方法が同じか
- syntheticと分子入力の違い
- 同じ情報アクセス条件か
- 実測費用、解析上界、モデル上のforecastのどれか

**異なる契約の改善率を、そのまま同じランキングへまとめないこと。**

実際に比較できない場合は、比較不能な理由を記録する。

## 4. 作業C：資源構造とボトルネックの整理

今回の中心的な作業である。

過去の研究結果から、量子シミュレーションの資源費用を決める要因を整理する。

### C1. 回路単価

既存資料から、次の項目を確認する。

- 任意角回転のnative合成費用
- controlled回転の費用
- basis changeの費用
- Clifford／non-Cliffordの内訳
- 同一角回転の共有や回路最適化の可能性
- DF・Gaussian blockなど特有の回路費用

### C2. Sampling・正規化・統計予算

次を整理する。

- 係数L1正規化
- second moment
- range／最大weight
- importance sampling
- 必要な十分試行数
- 多step化によるsampling overhead
- アルゴリズムの回路単価と統計費用の交換関係

### C3. 実行全体の費用

既存資料から、可能な範囲で以下を確認する。

- step数とstepあたりの発展時間
- 状態準備・読出し・共通wrapper費用
- classical setupとonline sampling
- 回路生成に必要な情報アクセス
- 合成器・precisionによる費用変動
- 主対象のPR／RPE／QPEで実際に重要となる資源

**既存資料に実費用がない項目は、0や推定値で補わず`NOT_MEASURED`または`NOT_ESTABLISHED`と記録する。**

特に、Parent allocationのh=0で得られた利益を、準備費用を含む総資源改善として扱わない。

### C4. 横断的な知見

上記を踏まえ、既存証拠から以下を整理する。

- 過去の方法が改善できた資源
- 逆に悪化させた資源
- 改善率を支配した条件
- 異なる方法で共通して現れた制約
- 今後の設計で避けるべき問題
- まだ解決されていない具体的な技術課題

ここでは証拠を整理することを優先し、新しい理論的結論や研究方針をCodexが確定しない。

## 5. 作業D：次のGPT科学レビュー用Decision Packet

作業A〜Cを踏まえ、次の研究テーマをGPTが選定するためのDecision Packetを作成する。

**目的は、次の研究テーマをCodexが決めることではなく、GPTが十分な根拠に基づいて判断できる比較材料を用意すること**である。

### D1. 次の研究方向の候補

既存の証拠から検討する価値がありそうな方向を、3〜5程度の候補群として整理する。

例えば、以下のような方向が考えられる。

- 正規化を悪化させずにnative回路費用を削減する方法
- Hamiltonianの前処理・分解方法の改善
- 乱択回路の構成とnative synthesisの共同設計
- 多stepでのsampling・weight増大を抑える方法
- Return aggregationから得た構造的知見の別方式への応用

これらは例であり、すべてを採用する必要はない。

過去の研究資料で根拠が弱い候補は、無理に残さないこと。

また、より有望な候補が既存資料から見つかった場合は追加してよい。

### D2. 各候補の比較材料

各候補について、以下を整理する。

1. 解決しようとする具体的な問題
2. 既存アルゴリズムとの差分
3. 想定する改善機構
4. 改善が期待される資源
5. 悪化する可能性がある資源
6. 必要な数学的・技術的条件
7. 関連する既存の研究成果
8. 近接する先行研究
9. 現時点で不足する証拠
10. 最小限の検証を行う場合の候補案
11. どの結果なら研究継続・終了の判断材料になるか

候補の科学的新規性や有効性を、確立した事実として記述しないこと。

**新しい研究テーマの科学的な優先順位・GO/STOPは、次のGPTレビューに委ねる。**

Codexが技術的実現性や資料の充足度を整理することは許可するが、科学的な採択判断と区別する。
