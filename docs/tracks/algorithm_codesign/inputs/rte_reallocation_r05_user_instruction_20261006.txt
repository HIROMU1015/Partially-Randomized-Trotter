# 1. 今回固定するcandidate A

以下のcandidateを比較対象Aとします。

\[
\widehat R=\sum_\ell p_\ell Q_\ell,\qquad
p_\ell\ge0,\quad \sum_\ell p_\ell=1,\quad
Q_\ell^\dagger=Q_\ell,\quad Q_\ell^2=I.
\]

**相互可換性、Pauli closure、Pauli wordへの効率的集約を仮定しません。**

\[
M=P_m(-i\sigma x\widehat R),\qquad
m=2d+1.
\]

\[
t_k=x^k/k!.
\]

A-familyは

\[
b_{-1}=0,\qquad
a_k+b_{k-1}=t_k,\qquad
b_m=0,\qquad
a_k,b_k\ge0
\]

とし、

\[
c_k=\sqrt{a_k^2+b_k^2},\qquad
\phi_k=\operatorname{atan2}(b_k,a_k),
\]

\[
U_k=(-i\sigma)^k
e^{-i\sigma\phi_kQ_0}Q_k\cdots Q_1.
\]

有限平均は

\[
\sum_k c_k\,\mathbb E[U_k]
=
P_m(-i\sigma x\widehat R).
\]

R0で証明済みの限定class optimumは

\[
B_A^\star
=
\sqrt{E_d^2+O_d^2},
\]

\[
E_d=\sum_{j=0}^{d}t_{2j},
\qquad
O_d=\sum_{j=0}^{d}t_{2j+1}.
\]

この数学を再発明せず、prior artとの関係を監査してください。

利用可能情報：

- \(x,m,\sigma\)
- \(p_\ell\)
- \(Q_\ell\)をsampleして実装するoracle
- \(Q_\ell^2=I\)

利用不可：

- 全Taylor word列挙

# 5. Peetz/CTSに対する必須監査命題

### C1: free-word / no-cancellation comparator

Pauli cancellationを一切使わず、
degree \(m=2d+1\) のtruncated Taylor coefficientsをそのままCTS型に分けた場合、

候補として

\[
L_c^{\rm free}=E_d-1,\qquad
L_s^{\rm free}=O_d
\]

になるかを**独立に導出して確認**する。

正しければ

\[
\mu_{\rm CTS}^{\rm free}
=
(E_d-1)+\sqrt{1+O_d^2}.
\]

Aは

\[
B_A^\star=\sqrt{E_d^2+O_d^2}.
\]

この場合、

\[
\mu_{\rm CTS}^{\rm free}-B_A^\star
\]

の符号を解析的に比較する。

上記式がCTSの定義と一致しなければ、修正して理由を記録する。
GPT側の推測を正解として扱わない。

### C2: collected comparator

Pauli collection/cancellationを許したCTSについて、

\[
L_c^{\rm coll},L_s^{\rm coll}
\]

を使ったnormalizationがAより小さくなり得るか確認する。

これはAの反証ではなく、

- A: I0 construction
- CTS collected: I1 construction

というinformation-access差として記録する。

### C3: Markov sampling

Peetz Supplementary Note 3のMarkov samplingが、

- full Pauli collectionを不要にするだけなのか
- \(L_c,L_s\)やcommon-angle distribution自体もI0だけでexact生成できるのか
- 同じfinite truncated target・同じnormalizationを保てるのか

を確認する。

もしI0だけでCTSがAと同等以上のnormalizationを達成できるなら、
Aのinformation-access deltaは消える。

### C4: atom-level equivalence

Aの各event

\[
e^{-i\sigma\phi_kQ_0}Q_k\cdots Q_1
\]

をCTS atomの特殊ケースとして直接表せるか確認する。

「一般LCUなら何でも表せる」はequivalence判定に使わない。
**CTSの具体的algorithmic constructionから直接生成されるか**を判定する。

### C5: general involution access

Peetz CTSはPauli algebraを前提としている。

Aの

\[
Q_\ell^\dagger=Q_\ell,\quad Q_\ell^2=I
\]

だけのaccessへCTSをそのまま拡張できるか確認する。

特に、DFで

\[
Q_\ell=V_\ell^\dagger Z_i V_\ell
\]

のようにbasisが異なる場合を念頭に、

- Pauli word collection
- basis multiplication
- common-angle atom生成

がAと同等の情報・古典処理で可能かを監査する。

# 7. novelty classificationを固定する

各claimを以下のどれかへ分類する。

### EQUIVALENT

同じtarget・同じinformation accessで、
weight、event distribution、unitariesまでreparameterizationで一致。

### SPECIAL_CASE

Aが既知法の固定parameter choiceとして得られる。

### DIRECT_COROLLARY

event distributionは完全一致しないが、
Aの構成・closed-form optimum・boundが既知定理から
新しい主要アイデアなしに直接導かれる。

### MATHEMATICALLY_DISTINCT_BUT_FRAMEWORK_KNOWN

広い原理は既知だが、
Aのrestricted family theorem / explicit solutionは独立している。
ただしalgorithm noveltyは弱い。

### METHOD_DELTA_CANDIDATE

同じtargetに対して、少なくとも一つ：

- weaker information access
- closed-form acquisition avoiding prior classical construction
- provably different event family
- lower normalization in the same access model
- different implementation complexity

が残る。

### INCOMPARABLE_TARGET

target自体が異なり、noveltyの優劣を直接判定できない。
