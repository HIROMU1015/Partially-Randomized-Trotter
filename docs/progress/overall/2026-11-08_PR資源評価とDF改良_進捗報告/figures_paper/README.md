# 発表・論文用の図

現在の原稿で使う10点を、同じ文字・配色・線幅・軸表記で描画した版。
旧図は figures/ と figures_v2/ に保持する。

- SVG：文字をアウトライン化したベクトル図。拡大しても文字・線が荒れず、日本語フォントの追加導入は不要。
- PNG：600 dpi、白背景。本文中の表示にはこちらを使用。
- [図一覧](overview.png)：確認用の縮小画像。発表・論文へ貼る際は各図のPNG/SVGを使う。
- [figure_values.csv](figure_values.csv)：保存値・単位・固定出典の対応表。元CSVの表用データも保全している。

PFは灰、部分ランダム化は青、純RTEは緑を基本とする。DF最適化の比較では通常CDFが灰、PR-awareが青、ENTRYが緑。色に加えてマーカー、線種、ハッチングで区別する。

DFの方式比較では、原報告のB2を「PR（一部因子を保持）」、B3を「二体因子RTE（一体項PF）」と表示する。数値CSVの系列キーは出典対応のため変更しない。
