# Codex指示：最良2次PR・最良2次PFの理論費用とcompiled費用の比較図

Repository：`HIROMU1015/Partially-Randomized-Trotter`

## 1. 目的

今回のPR資源評価で、PRと決定論的PFのcompiled総費用に大きな差が見られなかった理由を調べるため、以下の2つの仮説を区別できる図を作成してください。

**仮説A：PFが理論費用の段階ですでに優秀だった。**

今回採用したB0/B0+Iなどの決定論的PFは、理論費用の段階からPRと同程度、またはPRより低費用だった可能性がある。

**仮説B：PFの方が理論見積もりからcompiled費用への低下が大きかった。**

理論費用ではPRが有利だったが、compiled費用になるとPFの費用が相対的に大きく下がり、PRの優位性が縮小した可能性がある。

どちらかを前提として作図してはいけません。**保存済みデータから確認できることを、そのまま可視化してください。**

今回の目的は原因の断定ではなく、2つの仮説を区別するための証拠を得ることです。

## 2. 比較対象

今回は図の分かりやすさを優先し、**2次PFを用いるPRと、2次の決定論的PFに限定**します。

### PR側

各系・精度について、登録された2次PR候補のうち、保存済みcompiled総費用が最小となる採用候補を使用します。

原則として、従来のH-chain比較に使用した探索Aの採用点を基準にしてください。

### PF側

各系・精度について、次の2次PF候補集合から保存済みcompiled総費用が最小の候補を使用します。

- Full PF S2
- B0 S2
- B0+I S2

**Full PFだけを比較相手にしないでください。**

今回知りたいのは、打切りPFを含めた最良の決定論的2次PFが、PRとどの程度競争力を持つかです。

PFとPRでは、保持因子数・qなどが異なっていて構いません。

ただし、対象候補は既存の登録集合と保存済み選択結果に限定してください。新しい候補探索・科学的な再ランキングは禁止です。

### 比較条件

- H2 / H4 / H6 / H8
- linear H-chain、隣接1 Å
- STO-3G
- 各系の保存tol-only DF
- T=0.8
- 状態準備費用P=0
- 通常signed bias
- numerical allowance倍率1
- 既存の同一精度・shot会計
- cosine/sine両軸のshot込み総RZ費用

精度は以下の5条件を対象にします。

- ε=0.05
- ε=0.01
- ε=0.005
- ε=0.001
- ε=0.0005

## 4. 最初に行う作業：データ充足性の確認

図の作成前に、各H-chain・精度について、選択された最良2次PRと最良2次PFの以下4値が存在するか確認してください。

| | PR | PF |
|---|---|---|
| 理論総費用 | G_PR_theory | G_PF_theory |
| compiled総費用 | G_PR_compiled | G_PF_compiled |

重要な条件：

1. 理論・compiledで**同一候補**を比較する。
2. 理論・compiledで**同じ保存shot数**を使用する。
3. 両方式で比較可能な理論ゲート費用モデル・計数対象を使用する。
4. SOURCE・Hamiltonian・状態・DF・control・cohort・回路条件の整合性を確認する。
5. Full PF・B0・B0+Iを区別する。
6. 理論期待値とcompiled有限標本平均の違いを保持する。
7. H4 legacy DF12と現行DF10を混同しない。
8. H6/H8の旧PR n8/n32と現行探索Aを無断で結合しない。

特に、**B0/B0+Iの理論総費用が保存されているか**を重点的に確認してください。

今回の理論費用はnative DF回路のRZ計数モデルです。元PR論文のToffoli論理資源そのものではありません。

また、PFのq依存compiled単価モデル推定値を、理論ゲート費用の代用品として使用してはいけません。

条件が一致しない場合は、比較不能として明示してください。

## 5. 作成する図A：理論・compiledのPR/PF総費用比

**目的：PFが理論段階から優秀だったのかを確認する。**

横軸：
H2 / H4 / H6 / H8

縦軸：
PR/PF総費用比

系列：
- Theory
- Compiled

定義：

\[
\rho_{\mathrm{theory}}
=\frac{G_{\mathrm{PR,theory}}}{G_{\mathrm{PF,theory}}}
\]

\[
\rho_{\mathrm{compiled}}
=\frac{G_{\mathrm{PR,compiled}}}{G_{\mathrm{PF,compiled}}}
\]

読み方：

- 比率1：PRとPFが同費用
- 1未満：PRが低費用
- 1超：PFが低費用

**精度ごとに1枚**作成してください。

データがそろわない系は欠測として表示してください。

理論段階とcompiled段階で候補を選び直してはいけません。まずcompiled側で採用された同じ候補対を理論側でも固定してください。

この図から、理論段階でのPR/PF優劣と、compiled段階での優劣がどう変化したかを確認できるようにしてください。

## 6. 作成する図B：理論費用からcompiled費用への削減率

**目的：PFとPRのどちらが理論見積もりから大きく安くなったかを確認する。**

横軸：
H2 / H4 / H6 / H8

縦軸：
総費用削減率（%）

系列：
- PR S2
- Best PF S2

定義：

\[
R_m=100\left(1-\frac{G_{m,\mathrm{compiled}}}{G_{m,\mathrm{theory}}}\right)\%
\]

同じ条件についてPRとPFの値を並べた棒グラフを基本としてください。

- 正：理論費用よりcompiled費用が低い
- 0：同じ
- 負：compiled費用の方が高い

負値がある場合も、そのまま表示してください。

精度ごとに1枚作成します。

ただし、保存データが十分にない精度は、無理に図を作る必要はありません。

## 7. 作図可能な条件が少ない場合

データ不足があっても、取得済みの比較可能な条件については図を作成してください。

例えばH4/H6の旧固定候補についてのみ理論・compiled比較が成立する場合は、その範囲で参考図を作成して構いません。

ただし、それを今回の現行H-chain最良2次PR・最良2次PF比較と同じ図に混ぜないでください。

以下を区別して報告してください。

- 現行の最良2次PR・最良2次PFについて比較できる条件
- 過去の固定候補でのみ比較できる条件
- compiled総費用はあるが理論総費用がない条件
- 理論モデルが異なり比較できない条件
- 候補・SOURCE・cohortの対応が成立しない条件

主比較が成立する条件が少ない場合は、空の主図を量産せず、既存データだけで成立する参考図とcoverage表を作ってください。

不足を埋めるために理論ゲート数の新規計算や新しい候補選択を始めてはいけません。
