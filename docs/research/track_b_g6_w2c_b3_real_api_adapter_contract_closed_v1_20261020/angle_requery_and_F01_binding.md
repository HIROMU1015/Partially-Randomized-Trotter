# Angle/requery・F01

受理eventの原Evidence identityとevent fingerprintを別に保持。Fullのqueryはword/child、Canonicalはgroup_index/raw_word/childも保持。requery outputをexact Documentとして封印し、fingerprint一致を要求する。

F3-shaped angleはcontextのsource/input/policy/preflight/sigma/event_id/parent/child、ratio、precision型、interval、representative/radius、signed値、宣言predicateを確認。原angle document/digestをsidecarに保持。これは精度宣言の整合検査であり、atan enclosureの数学的正当性の証明ではない。

人工backendのangleは固定Fraction区間であり実F3計算を呼ばない。`synthetic=true`、`mathematical_precision_verified=false`を保存する。actual enclosure/実precision費用は未測定。

sample/codec/evidence/bits/audit/angle/requeryの失敗は既存run_pair→F01へ渡す。completed prefix・inflight event・last trial・candidate hashを保存し、失敗trialを完了に加算しない。worker crash/ACK不明はUNKNOWNを保持し、未確認をZERO/PASSへ変換しない。

Canonical専用変換は原Legacy context(event_id=driver event digest、input/policy/preflight)と原angle bytesを保持する。Fullのsource/input/policy/preflight/sigma/parent/child contextとは別。共通interval検査だけ別の一時normalized documentで再利用し、保存原文を置換しない。Canonicalの実call引数(group_index,raw_word,child)を保持し、wordはbinding metadataとして区別する。

Layer Bの人工AuditParity-shaped Sealも、F3 codecと異なるdriver codecの原text/digest・identity/state/completed_calls_beforeを保存rawへ通す。実科学audit正当性は未確認。
