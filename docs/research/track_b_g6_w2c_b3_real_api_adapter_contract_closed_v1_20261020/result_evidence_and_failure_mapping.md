# Result・Evidence・failure

|原情報|保持/driver投影|
|---|---|
|EVENT|ACCEPTED、exact event、原document identity、別event fingerprint、EVENT|
|ZERO/RAW_NONREDUCED|trace/raw/draw-stageを確認、ZERO_R|
|ZERO/COIN_REJECT|traceとacceptance drawを確認、ZERO_C|
|IDENTITY|原情報保持、driver_kind=null、random zeroではない|
|deterministic EVENT query|EVENT_QUERY、sampling trialへ投影しない|
|typed failure|category/reason/stage/input/details/原bytes/digest、terminal STOP|

Full G7 Noneには原observation/trace/packet-call provenanceを必須にした。None単独では分類しない。Canonical NoneもZEROへ変換しない。word/raw/circuit-time word、child、proposal×weight=coefficient、phase/provider countを構造検証する。Full nonreduced rawをreduced wordへ成功変換しない。

ここでのtrace検査はSOURCE上のstructural条件と人工inputの一致確認。actual dyadic label map、local coefficient/child law、sampling lawを証明しない。必要なscience provenanceが欠ける場合は拒否し、値を推測補完しない。

AdapterFailureのoriginal F3-shaped failureはdetailsも含めて保全し、F01 frozen_failure_evidenceへ流す。generator/audit/angle/requery/precision/source/input/bits/evidence等のreason/stageは失わない。endpointは失敗後terminalで再sample不可。state/trace保存失敗はINCOMPLETE_EVIDENCEのまま。
