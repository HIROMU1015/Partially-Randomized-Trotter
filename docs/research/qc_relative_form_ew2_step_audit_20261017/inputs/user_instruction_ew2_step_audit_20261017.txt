## 2. 固定する数学的問題

有限次元の共通不変sectorにおいて、

\[
H=LI+G,\qquad
G=\sum_{j=1}^{M}F_j,\qquad
0\preceq F_j\preceq f_jI,\qquad
\Lambda=\sum_jf_j
\]

とします。

元Hamiltonianのground energyを \(E_0\) とし、

\[
e=E_0-L\ge0,\qquad
W=U-L\ge e
\]

とします。

\(L,U\) は認証済みの入力情報であり、真の \(E_0\) やground vectorを古典oracleとして与えません。

正stageの対称二次PFについて、

\[
K(h)=\frac{i}{h}\operatorname{Log}S_2(h)
\]

を定義します。

既存監査で成立を確認した相対形式は、

\[
-\eta(h)G
\preceq K(h)-G
\preceq\eta(h)G
\]

です。

既存の十分上界：

\[
\eta_0(h)=
\frac{32(h\Lambda)^2}
{1-16(h\Lambda)^2}
\]

\[
\eta_1(h)=
h^2K_{\mathrm{SOS}}+
\frac{512(h\Lambda)^4}
{1-16(h\Lambda)^2}
\]

共通適用域は \(|h|\Lambda<1/4\) です。出力確率の議論では \(\eta<1\) も必要です。

両方が成立する同じ条件では、

\[
\eta(h)=\min\{\eta_0(h),\eta_1(h)\}
\]

を使用できます。

これらは検証対象の前提であって、任意のPFや大きなstepに適用できるという意味ではありません。

## 3. EW2の独立数学的検算

今回の第一の重要検証です。

前回GPTレビューでは、

\[
\Delta=K-G,
\qquad
R=G^{-1/2}\Delta G^{-1/2}
\]

を導入しました。

\(e>0\)、\(0\le\eta<1\) では、

\[
-\eta I\preceq R\preceq\eta I
\]

が成立し、

\[
\Delta K^{-1}\Delta
=
G^{1/2}R(I+R)^{-1}RG^{1/2}
\preceq
\frac{\eta^2}{1-\eta}G
\]

が得られるとしています。

元ground状態上の \(K\) のスペクトル測定値を \(Y\) とすると、

\[
\mathbb E\left[\frac{(Y-e)^2}{Y}\right]
\le
\frac{\eta^2e}{1-\eta}
\]

となり、最終的に、

\[
\boxed{
\Pr(|Y-e|>d)
\le
\min\left\{
1,
\frac{\eta^2e(e+d)}
{(1-\eta)d^2}
\right\}
}
\]

および、

\[
\boxed{
\Pr(|Y-e|>d)
\le
\min\left\{
1,
\frac{\eta^2W(W+d)}
{(1-\eta)d^2}
\right\}
}
\]

を導出しています。

これを便宜上EW2と呼びます。

### 重点検証事項

1. \(G^{-1/2}\)、\(K^{-1}\) が使用できる条件。
2. 行列積の順序と非可換性。
3. 相対形式から \(R\) のspectral boundを導く手順。
4. \(R(I+R)^{-1}R\) の上界。
5. ground状態での期待値と、\(K\) のspectral outputの対応。
6. 上側・下側tailに対する不等式。
7. \(e\) を認証上界 \(W\) へ置き換える際の単調性。
8. ground縮退・ground空間上の混合状態。
9. \(e=0\)、\(W=0\)、\(d>0\)、\(\eta=0\) 等の境界条件。
10. 元EWとEW2のどちらが有利になるか、その適用条件。

**逆演算子は証明のために導入されているだけです。**

\(G^{-1/2}\)や\(K^{-1}\)を実際の量子回路で生成する必要がある、という解釈をしないでください。

逆に、証明中で成立していない逆の操作を、無料oracleによって救済してはいけません。

### step選択式の検算

GPTレビューでは、

\[
c=
\frac{\alpha_{\mathrm{spec}}d^2}
{W(W+d)}
\]

に対して、

\[
\frac{\eta^2}{1-\eta}\le c
\]

の十分条件を、

\[
\boxed{
\eta\le
\eta_*=
\frac{\sqrt{c^2+4c}-c}{2}
}
\]

としています。

この変形を独立に検算してください。

さらに、

\[
h\le
\frac1{\Lambda}
\sqrt{
\frac{\eta_*}
{32+16\eta_*}
}
\]

がRF0から導かれる十分step条件として正しいか確認してください。

\(W=0\)や\(\Lambda=0\)など、割り算が定義されない場合は別に扱ってください。

## 4. 既知の交換子ノルム保証との比較

今回の第二の重要検証です。

既存のChildsらの二次PF誤差保証に対して、固定された同じ順序のPFで、

\[
C_2=
\sum_{j<M}
\left\{
\frac{\|[F_j,[F_j,R_j]]\|}{24}
+
\frac{\|[R_j,[R_j,F_j]]\|}{12}
\right\}
\]

\[
R_j=\sum_{k>j}F_k
\]

とします。

既知の実時間operator上界として、

\[
\|S_2(h)-e^{-ihG}\|
\le |h|^3C_2
\]

を利用しています。

まず、この上界が、引用論文の正確な式・係数・演算順序・仮定と一致するか確認してください。

実際の比較では、取得可能な認証上界

\[
\overline C_2\ge C_2
\]

を使用します。

高価なmany-body normの真値を無料で与えてはいけません。

### 4.1 逆log評価の検算

レビューでは、

\[
x=|h|\Lambda<1/4
\]

として、log級数と非可換なべきのtelescopingから、

\[
\boxed{
\|K(h)-G\|
\le
\frac{h^2\overline C_2}
{2-e^{|h|\Lambda}}
\le
\frac32h^2\overline C_2
}
\]

を導いています。

次を検証してください。

- 比較する二つのunitaryが同じ解析的log branchに入る条件。
- それぞれの `operator − I` に対するnorm bound。
- 非可換なlog級数の差に関する評価。
- 分母 \(2-e^{|h|\Lambda}\) の導出と正値性。
- 定数 \(3/2\) の適用域。
- 既存Childs上界の必要条件との整合性。

レビューの式を前提にするのでなく、独立に式変形を確認してください。

### 4.2 同じenergy-windowへの接続

元ground状態上で、

\[
\mathbb E(Y-e)^2
=
\|(K-G)|g\rangle\|^2
\]

が成立することを確認してください。

そのうえで、

\[
\Pr(|Y-e|>d)
\le
\min\left\{
1,
\frac{b(h)^2}{d^2}
\right\}
\]

\[
b(h)=
\frac{h^2\overline C_2}
{2-e^{|h|\Lambda}}
\]

を検証してください。

これが正しければ、既知の交換子保証も、励起gapや特定PF固有枝への高overlapなしでenergy-windowへ接続できます。

**相対形式保証だけがgap-freeである、という誤った比較を行わないでください。**

## 5. 有限stepでの優位条件の整理

数学的成立が確認された場合、EW2と交換子対照を同じ条件で比較してください。

以下を必ず揃えます。

- 同じ元Hamiltonian
- 同じ対象sector
- 同じ実装可能なPSD分割
- 同じPF次数・演算順序
- 同じ絶対energy origin
- 同じground state access
- 同じ目標energy精度
- 同じ成功確率
- 同じQPE読出し条件
- 同じ合成誤差の扱い
- 同じ証拠取得・前処理の費用規約

### 5.1 記号的な有限step比較

EW2から得られる十分step条件と、交換子保証から得られる十分step条件を、それぞれ明示してください。

単なる漸近式だけでなく、

\[
|h|\Lambda<1/4,\qquad
\eta(h)<1
\]

や、

\[
\eta(h)^2/(1-\eta(h))\le c
\]

など、実際の有限step条件を保持してください。

結果として、次のような問いに答えられるようにします。

**「どの認証された入力条件で、相対形式保証が、既知の強い保証より大きな実行stepを許すのか」**

既知対照には、必要以上に小さいstep領域や、意図的に粗い係数を強制してはいけません。

比較に利用可能な別の正当な保証がある場合、その存在と適用条件を記録してください。

### 5.2 Xiの検証

前回レビューでは、説明用の小step領域について、

\[
\eta(h)=ah^2+O(h^4)
\]

として、

\[
\boxed{
\Xi=\frac{aW}{\overline C_2}
}
\]

を導入しました。

RF0では \(a=32\Lambda^2\)、RF1では条件付きで \(a=K_{\mathrm{SOS}}\) です。

検証対象は次のとおりです。

1. Xiの導出と単位。
2. Xiが比較に有効な漸近領域。
3. Xiと実際に許容されるstepの関係。
4. 比較に使うconfidence・誤差予算の係数。
5. \(\overline C_2=0\)、\(a=0\) 等の特異条件。
6. 有限stepの高次剰余による影響。
7. Xiが小さくても実際の量子資源改善が保証されない理由。

**Xi<1をそのまま研究GO条件にしてはいけません。**

数値的な閾値・改善率・実分子での優位性を、今回新たに設定・主張しないでください。
