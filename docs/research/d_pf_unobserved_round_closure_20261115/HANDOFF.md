# D → C・統合担当：決定論PFの未観測60軸（m7・m8・m10〜m12）

根拠はすべて[REPORT](REPORT.md)にある。今回は静的な調査だけで、compile・保存回路の読込み・価格予測・fit・N・Gは0件である。

## 結論

**保存証拠と実装から言えること**
- 6候補とも、未観測roundの入力は観測済みroundと同じpiece列を繰り返したもので、bit単位で一致する（metadata検査540件、PASS）。
- roundによって変わる角度は、最後のancilla runに入るscalar位相 `p(−scalar·T)` だけである。
- Qiskit 1.3.0・opt1・coupling mapなしの経路では、書換えは局所的にしか起きない。
- 各pieceのone-body方向制御が、全wireで書換えの伝播を止める障壁になる。
- このため、固定幅のcompiled RZ数は `A + B·q + δ` の形になる。δは各軸で0または−1で、最後のancilla runでだけ生じる。

**保存済みの一致との関係**
- m4/m5で厳密に較正でき、m6・m9の予測も完全一致した。12モデルの切片は共通の307で、X=Yだった。
- これらは上の構造と整合する。
- ただし、一致した事実からm7・m8を補間したり、m10〜m12に2%条件を適用したりはしていない。

**未確定のこと**
- N1：最後のrunの角度にどれだけ余裕があるか。
- N2：障壁の角度が数値的に十分か、またcompiled回路が実際に周期的か。保存回路ではまだ確かめていない。
- 60軸の具体値は計算していない。

**Fullとp7で違う点**
- Fullでは、凍結した傾きが Y4 = 3·S2 + 162、M5 = 11·S2 − 48 になる。p7は3倍・11倍に厳密に一致する。
- つまりFullでは、piece当たりのcompiled価格がsigned timeに依存する。piece価格を幅や公式の間で移してはいけない。
- 固定幅のq依存は、この影響を受けない。

## C向け

1. 凍結JSON（`12372fa6`）、m6・m9の判定、較正は変更していない。資格の値も変わらず、`qualified_for_candidate=false`、`long_q_extrapolation_qualified=false` のままである。
2. 判断をお願いしたい点：閉包から導いた価格（凍結した直線に、§6の監査結果を添えたもの）を、m7・m8・m10〜m12の価格としてG比較に受け入れる余地があるか。受入の基準も含めて決めてほしい。
   - 受け入れない場合、終端の直接観測が必要になる。次の作業は、BのNで重みが大きいgroupのm12直接取得に変わる。
   - 見積り：Full M5で約11.8 h、RSS 35〜50 GiB。全12軸で約35 CPU-h。
3. 今回の結果を根拠に、60軸の価格を表に入れないでほしい。2%を外挿したことにもしないでほしい。
