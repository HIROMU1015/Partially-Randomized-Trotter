## 2. 今回の数学的前提

対象sector上で、

\[
H=LI+G,\qquad G=\sum_jF_j,
\]

\[
0\preceq F_j\preceq f_jI,\qquad
\Lambda=\sum_jf_j
\]

とします。

元Hamiltonianのground energyを \(E_0\) とし、

\[
e=E_0-L,\qquad
W=U-L\ge e
\]

です。

既存保証には、

\[
-\eta(h)G
\preceq K(h)-G
\preceq\eta(h)G
\]

があり、

\[
\eta_0(h)=
\frac{32(h\Lambda)^2}{1-16(h\Lambda)^2}
\]

\[
\eta_1(h)=
h^2K_{\mathrm{SOS}}+
\frac{512(h\Lambda)^4}{1-16(h\Lambda)^2}
\]

を利用できます。

条件は原監査に従い、正stageの対称二次PF、共通不変sector、適切なlog branch、\(|h|\Lambda<1/4\) 等を維持してください。

EW2による十分条件と、既知の強化交換子対照については、直前の固定資料を正本としてください。

**今回はこれらの数式を再証明しません。**

検討するのは、必要な認証情報が実際の量子化学Hamiltonianから取得可能か、その取得費用が妥当かという技術的問題です。

## 3. Step A：実装可能なPSD分割の確認

既存の電子Hamiltonian・DF実装・SOS関連資料を調べ、次を確認してください。

1. 既存の分割を、実装可能なPSD fragment \(F_j\) として扱える条件。
2. 各fragmentの正半定値性を保証できる条件。
3. 各fragmentが対象の論理sectorを保存する条件。
4. 元Hamiltonianとの同値性、scalar、nuclear repulsion、normal orderingの扱い。
5. 各 \(e^{-ihF_j}\) を既存のGaussian/DF/native回路で実装できるか。
6. PSD化のためのshiftが、回路費用や \(\Lambda,W\) を悪化させる可能性。
7. 元のHamiltonianと近似DFモデルの差をどう管理しているか。

**形式的にPSD分割が存在することと、その分割を安価に実装できることを区別してください。**

特に、既存のDF平方に負の係数が含まれる場合、それを単にPSD fragmentと呼んではいけません。

また、SOS/BLISSによって数学的なPSD表示を得られても、その分割の指数関数が既存の低費用DF回路で実装できるとは限りません。

今回は新しいSOS分割やDF係数を生成しないでください。

**既存資料で確認できる具体的な入力classを優先し、調査対象を無制限に増やさないこと。**

## 4. Step B：必要な認証情報の取得可能性

以下の各量について、既存SOURCEと保存資料から取得できるかを調べてください。

| 必要量 | 確認する内容 |
|---|---|
| \(L\) | 実装するPSD分割と整合した認証済み下界 |
| \(U\) | 同じHamiltonian・sectorの認証済み上界 |
| \(W=U-L\) | 認証区間幅と取得条件 |
| \(f_j\) | 各fragmentの正当なoperator norm上界 |
| \(\Lambda\) | 同じ分割に基づく認証された上界 |
| \(K_{\mathrm{SOS}}\) | 既存K0辞書・行和評価から取得可能か |
| \(\overline C_2\) | 同じPFに対する交換子normの認証上界 |
| state access | ground状態・近似状態を準備するための前提と費用 |

それぞれについて、次を区別してください。

- 既存の認証済み値・証拠がある。
- 値や推定値はあるが、数学的certificateではない。
- 既存SOURCEで計算可能と思われるが、未実行。
- 理論的な取得方法はあるが、実装・取得費用が不明。
- 必要な情報・実装が不足している。
- 今回の調査範囲では判定不能。

**経験的数値、既知のFCI真値、保存ground vector、未認証の近似normを、無料の認証入力として扱わないでください。**

\(U\) は正しいHamiltonianに対する検証可能な上界でなければなりません。例えば変分エネルギーを使う場合、その計算・数値誤差・元モデルとの対応を含めて確認してください。

\(K_{\mathrm{SOS}}\) は既存K0の生成方法を再利用し、\(\overline C_2\) は強い既知対照に公平な取得条件を適用してください。

今回、新たな係数・norm・固有値を数値的に求めたり、保存値から計算し直したりしてはいけません。

| `PREFLIGHT_READY_FOR_SCIENTIFIC_DESIGN` | 適切な入力classと必要な証拠の取得経路が確認でき、次の限定科学検証を設計できる |
