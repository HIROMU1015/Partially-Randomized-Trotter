**path1の不一致の性質**
- 最初のstepで、入口の最後の1q runの中の1 tokenが違った。その後の最初の多qubit tokenは位置377で、そこから先は区切りと多qubit tokenが一致している。
- 固定した入口Fが、13個の最初のstepだけから決めた共通部分で、つなぎ目の1 tokenまで含んでいたためである。
- 事後の補足（判定外）：path1の2番目以降の511 stepは、入口・末尾とも一致した。

**R=526の2番目以降のstepの本体**（X軸、2 path・1,022区間）

## B2向け：順位反転の境界を解釈するときに、S0+で狭まった不確かさ

| 不確かさ | S0+の後 |
|---|---|
| q方向の構造 | **q=512まで観測で確認した**（S0-r1のq ≤ 64に加えて）。stepあたりの決まった定数1900 RZと切片308 RZは、q=512でも同じだった |
| 有限pathのばらつき | R=526での2番目以降のstepの標準偏差は58 RZ。1 pathの標準偏差は約1,300 RZ（総数の約0.05%） |
| eventあたりの分散 | 2番目以降のstepでは、R=33・66・526で5.8〜7.0。Rに比例するという仮定と矛盾しない |
| eventあたりの平均 | 2番目以降のstepで6.78（R=33）、6.52（R=66）、6.34（R=526）。R=4205の最初のstep（n=2）で6.34 |
| q ≥ 1024（m10〜m12、event数の約97%） | 未観測。局所的な書換えの論証と、q ≤ 512での観測による |
| R=1052・2103のstep law、R=4205の2番目以降のstepのばらつき | 未観測 |
| order2・非自明な位相、sampler law | 変わらない（UNKNOWN、未資格） |

**まとめ**
- 観測範囲（q ≤ 512）では、step分解の構造と小さなばらつきが保たれた。総額をT_refより75〜82%下げるような現象は見られなかった。
- 残る不確かさは、q ≥ 1024とR ≥ 1052への延長である。

## C2向け

- C2のm9の予測・価格・比較（+0.274418%）は変更しておらず、再利用しただけである。
- m9の2 pathの差（1,879 RZ）は、stepごとの本体の差としてすべて説明できる。決定論部分は同一である。
- 単一step cellの較正標本（R=526で分散0.5）は、長いpathの中のstepのばらつき（R=526で分散3,314）を代表しない。ばらつきの推定には、2番目以降のstepの値を使うのが適切である。
