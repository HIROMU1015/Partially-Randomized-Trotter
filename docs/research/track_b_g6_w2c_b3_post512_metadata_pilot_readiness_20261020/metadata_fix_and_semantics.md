# 将来SOURCEの限定修正

versioned execution.Coordinator.reportで、既にgate/preflightを通るmanifestを基にmetadata.context/stamp_reportを使い継承既定値を訂正する。単純なFalse固定ではなく、Artificial/Live flags、Mock scope、USER approval本文SHA・target bindingの整合を確認する。formatterは実行権限ではなく、保存済み承認を入力した人工testもpermitを発行しない。未承認dispatchは元gateで拒否する。

同じexecution_metadataをfinal/条件receipt/receipt/STOP/delivery/callerへ伝え、Store snapshotに実行type・approval mode・external_authority_used=False・claim_spent・run_statusを分離する。legacy real_authority=Falseは外部service不使用のaliasとして保持し意味を明記する。snapshotに呼出manifestと実claim bindingの不一致があっても診断原本を失わず、execution_metadata_verified=Falseを返しofflineは拒否する。

live_API_compatibilityとscience_correctness_certifiedは従来どおりNOT_ESTABLISHED/False。別のlive_API_observationに固定manifestの完了prefixとscopeだけを記録し、一般保証、範囲外入力、実F01未発生を分離する。Artificial failureは実科学F01観測とは記録しない。

offline.inspectはmanifestからmodeを推定し、明示引数との不一致を拒否する。metadata.pyをpinした新SOURCEでは全artifactの新metadataを必須照合。旧pin inventoryには新metadataがなく、旧結果を新schemaで書き換えない。今回の旧512訂正は別sidecarに限定する。

科学Core、Exact Adapter、Global Bundle、F01、Storage V2、wrapper/sample/angle/requery/Bits、worker/run_pair/scheduler bodyは不変。新準備SOURCEのactivation anchorはNoneへ閉鎖する。旧anchorを新SOURCE/new digestへ移して消費済みの承認を再利用しないためであり、旧測定SOURCEの承認anchor・claim・STOPは不変。新実行grant/permit/claimは0。

production_permission=Falseはreceiptが追加実行を認可しないという意味を保持。TEST_ONLY schemaは人工artifactにのみ残す。親guard.artificial_only=Trueは親がCoreをloadしないguard観測のlocal fieldで、execution modeではないためguard_observation_scope=PARENT_IMPORT_GUARD_ONLYを添える。準備candidateのFalse/未承認descriptorは現在の新SOURCEが実行承認されていないことを表し、過去512件の結果へ遡及しない。
