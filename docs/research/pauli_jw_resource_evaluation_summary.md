# Pauli-JW時間発展の資源評価：H2・H4・H6の研究成果

2026-10-26時点の保存結果を統合した研究案内。対象はlinear H2/H4/H6、隣接1.00 Å、STO-3G、S2、T=0.8である。
**最新の保存Hybrid対純RTE比較では、15精度条件中14条件で純RTE、H4のε=.05だけでHybrid PRの標本平均Gが低い。**
これは有限候補・仮想ρ=0・有限価格標本の観測結果であり、方式一般の優劣、母平均費用、大域最適性、実compiled精度の証明ではない。5精度は価格標本を共有するため、15個の独立実験でもない。
本資料は既存結果の引用・体系化であり、新しい候補選択、数値解析、重要claimの正式採択、論文本文の改訂ではない。

## 1. 研究目的・背景

部分ランダム化時間発展では、回路の一部を確率的なunitary eventへ移すことで単回価格を下げられる一方、normalizationと信号biasにより必要測定回数が増え得る。
本系列では、その競合をPauli-JW Hamiltonianの実際のcompiled回路と同じ信号精度の会計で調べた。Hybridの勝利を前提にせず、切り捨てる・全て保持する・部分的にランダム化する・全非identity項をランダム化する、という境界を比較対象に含めた。

| 方式 | 保持部とtail | 本系列での意味 |
|---|---|---|
| Full PF | 全M非identity項とconstantを保持、random tailなし | 対称2次PF（S2）の決定論的対照。qを有限候補から比較 |
| B0/B0I | 保存係数順prefixを保持し、残りを切り捨てる | 切り捨て決定論的S2。Pauli実装はconstantを常に保持するため、同じprefix/qのB0とB0Iは同等な範囲で重複計算しない |
| Hybrid PR | 0<L_D<MのprefixをS2で保持し、tailをfinite RTEへ | 保持half→r event→保持reverse halfをq step。prefix/q/r/Kの有限探索 |
| 純RTE | L_D=0、全非identity項をfinite RTEへ | constant phaseは保持。「純」はconstantまで捨てるという意味ではない |

旧資料の「PR」は純RTE境界を含む広いfamilyを指す場合がある。「PRがPFより低G」と「Hybrid化自体が有利」は異なる主張である。
初期の固定PR、後続のPR探索、Hybrid対純RTEの直接比較を分けて読む。[元研究][base-study]、[H4 PR探索][h4-search]。

## 2. 科学モデル・評価方法

| 条件 | H2 | H4 | H6 |
|---|---|---|---|
| Pauli非identity項M | 14 | 184 | 918 |
| System / ancilla wire | 4 / 4 | 8 / 8 | 12 / 12 |
| State | 旧non-DF pilotの保存raw state | 保存H4共通raw state/ray | 元H2/H6研究で同一MO積分のPauli full-Hから取得したsector最低固有vectorを保存・再利用 |
| 今回までの更新で再利用したreference | 保存full-H reference | 保存full-H reference包含区間 | 保存full-H reference（Duhamel包含） |

共通条件は中性singlet、1.00 Å/STO-3G、T=.8、S2。各分子内で同じHamiltonian・raw ray・exact squared normを共有し、方式ごとに再正規化しない。分子間ではstate/referenceが異なる。
Hamiltonianはconstantと非identity Pauli項を分け、prefixは保存されたabs係数降順・label tie-breakを維持する。H6のstate生成は元研究で行った作業で、後続event拡張や本資料で再生成したものではない。[入力と数値モデル][base-study]。

Finite RTEはpaired Taylor法則。Kは最大偶数event次数であり、K2/K4のevent orderは0/2、0/2/4、対応する通常多項式次数はK+1である。
各eventのsigned Pauli product、rotation、order phase、constant phaseと演算順序を保存する。実装のCDF/53bit uniform-wordモデルとIID仮定を明記し、PRNG streamの数学的独立性まで証明したとはしない。
純RTEではs=q*rが重要だが、同じsのq/r分解が浮動小数点処理・seed・compiled価格まで同一とは仮定しない。

現在の主比較はcentral-rotation control。Qiskit1.3.0、basis `rz/sx/x/cx`、optimization_level=1、seed=17、topology/coupling/layout/routingの追加指定なし。
Full Hadamard wrapperのcosineと+Im sine（final H前のSdg）を含め、状態準備費用を除くcompiled RZ数を価格Cとする。Generic whole-body controlは別系列として保全する。

### B・bias・N・C・Gの関係

軸aの有限RTE信号にB_savedを一回適用して理想referenceとの差b_aを評価し、数値包含allowance u_aと未保証のcompiled実装残差ρ_aを区別する。
元の会計は、ε_a=元のbinary64 ε_sig/√2、α_a=.025、h_a=ε_a−|b_a|−u_a−ρ_a、h_a>0、(u_a+ρ_a)/h_a≤.01の下で、

$$
N_a=\left\lceil\frac{2 B_{\rm up}^2\ln(2/\alpha_a)}{h_a^2}\right\rceil,
\qquad \widehat G=N_{\cos}\widehat C_{\cos}+N_{\sin}\widehat C_{\sin}.
$$

B_upは各保存会計の外向き上界である。古いlog marginを含むB_upと後続の共通会計を勝手に同一化しない。
主評価のρ=0は仮想条件。実ρ=0、または実ρが保存guard内にあることを意味しない。本資料では式を再実行していない。

**Nは量子測定shotの十分条件による会計値、nは古典的にcompileしたtrajectory価格の標本数。** 実量子shotをN回実施したわけではない。
PRのCは有限標本平均であり、同一trajectoryの両軸価格からGのSEをpaired会計する。探索と独立確認は混合しない。決定論的価格のn=1はMC平均の標本誤差を表さない。
Ideal-law meanのArb/L2包含、選択回路の局所Arb保証、全lawのcompiled残差保証、正式certificate受理は別の証拠である。[会計と限界][h2-latest]、[Pauli/DF整理][df-synthesis]。

## 4. 最も重要な科学的知見

### 4.1 単回価格の低下と総費用の低下は別である

H4のprefix27/q8 B0は両軸868 RZと安いが、cosine bias約0.182803のため指定5精度では不適格だった。一方、決定論的prefix探索では精度に応じた別候補が適格になった。
切り捨てるほど常に得という説明は成立せず、単回Cだけでなくbias・headroom・Nを同時に見る必要がある。[B0比較][h4-b0]。

同じB0研究のε=.05では、固定PRの平均C約1140.8046875に対しB0は1248 RZと高いが、B=1のshot負担によりB0 G=23,237,760が固定PR G=26,673,154.3984375より低かった。
これは旧prefix27固定PRとの比較であり、PRを探索した後の結果ではない。[保存B0表][h4-b0]。

### 4.2 H2：有望な探索候補の確認不足が比較を変えた

旧確認はRTE q1/r2/K4とHybrid q1/r4/K4の各n96で、Hybrid低Gだった。探索n8では他の低G候補が存在した。
追加検証は指定3候補に、不確かさから競合し得た5候補を加えて確認した。新確認集合minでは全5精度RTE低Gへ変化した。
H2の改善は大sへの拡張によるものではなく、既存s4候補の独立価格確認で比較集合が充実した結果である。確認後選抜と逐次延長を含むため、厳密な選抜補正済み母平均保証ではない。[H2確認coverageと結果][h2-latest]。

### 4.4 H4：大きいsへの延長は改善しなかった

H4ではs128・256でBとNは下がるが、Cの増加が上回りGは悪化した。保存s64のRTEが良好なままで、.05のHybrid低G／他4精度のRTE低Gという直接比較は維持された。
s64近傍は調査grid上の結果であり、q/r/K連続域の単峰性・大域最適性の証明ではない。[H4既存図][h4-fig]、[H4/H6報告][ext-latest]。

### 4.5 決定論的対照とPR側の探索機会を揃えることが重要である

H4 B0/B0Iは106構成を比較し、5精度の最良prefix/qは132/1、144/2、176/2、180/8、180/8となった。旧prefix27/q8の不適格結果だけでは決定論的familyを代表できない。

「PF/PRの順位」は候補集合・精度・選抜手順を伴う記述である。現在のHybridも保存された有限探索familyで、RTE追加探索に合わせて再最適化したわけではない。[B0][h4-b0]、[PR探索][h4-search]。

## 5. DF-native研究との関係

DF研究と共通するのは、同じ信号精度に対する単回compiled価格とshot負担の比較である。Pauli系列は、表現・control・prefix・finite law・候補探索の依存を可視化する追加のcase studyとして位置付ける。

| 比較軸 | Pauli系列 | 既存DF-native系列で区別すべきこと |
|---|---|---|
| 入力 | 保存JW Pauli項＋constant | 固定H4対照は同じMO積分からのtol-only1e-8/rank10。数値的一致診断と厳密同一は別。H6の旧DF stateを新Pauli stateへ移植しない |
| 分割・保持 | Pauli係数順prefix。初期H4 prefix27はZ/ZZのみ | one-body＋二乗fragment、fragment順位とtail抽出後involution係数は別。Pauli27対DF1を同等な分割としない |
| Random event | tail signed Pauli productとrotation | rotated Z/ZZ involution。law/component/normalization/angleが異なり、同じq/r/Kでも同じ分布ではない |
| 回路・reuse | genericまたはcentral rotation | Gaussian basis変換とcentral diagonal、occurrence内のbasis reuse。単純なliteral加算ではcompiled価格にならない |
| Cohort | n8探索、候補ごとの独立確認、旧固定n256は別 | DFの保存n256とは別law。共通indexをPauli/DFのpaired標本としない |
| 数値政策 | 新探索は各候補固有の包含・B/guard。主Gはρ=0 | 旧C/L、log margin、normalization/certificate gate、reference転送の保証範囲を別に保持する |

固定H4の保存単価はDF PF135355、DF PR平均23678.44140625 RZ。Pauli centralのPF15028／PR平均1140.8046875とは大きい差があるが、普遍的なPauli表現優位ではない。[Pauli/DF整理][df-synthesis]。
D1初回fingerprint FAILと後続SOURCE基準Bで完了した9構成の診断は別の来歴。後者は保持/event費用と非加法性を示すが、basisやcompiler passの一意な寄与率は未分離である。
旧DF成果・失敗・未受理状態は残し、この総合資料をDF statusの更新として扱わない。

## 7. 限界・未解決事項

- 主Gは仮想ρ=0。保存guardの感度結果と、実ρがguard内にあることの保証は別である。

- 原子間距離1Åの保存rayでの信号評価である。状態準備、実機ノイズ、FT gate合成、energy精度や全QPE/RPE interrogation費用への外挿を含まない。
