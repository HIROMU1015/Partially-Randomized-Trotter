# リポジトリ収録範囲

2026-11-03 JST。本版はユーザーが許可した匿名化監査metadataの収録を反映する。対象GitHubリポジトリはpublic（誰でも閲覧可能）であることを確認し、その前提で追加許可を受けた。過去の公開拒否は当時の記録として保持し、今回の対象に関する収録制約を本版で更新する。

収録するのはREPORT.md、H8_CONFIRMATION_EVIDENCE.csv、PUBLICATION_SCOPE.md、VALIDATION.json、COMPLETION_AUDIT.json、AXIS_PROVENANCE.csvの6ファイル。既存結果・SOURCE・固定入力の科学的identity、原結果/native/terminal等の科学的hash、匿名の終了件数・exit/reap・seed監査の適用範囲、192軸のSOURCE/fingerprint/task-result hashを含む。これらのhashは再現性・原本対応のためであり、ユーザーの許可を証明するcertificateや台帳ではない。

内部path・host/IP・PID/UID・資格情報・private raw/input配列・seed実値/一覧・grant/承認原文・運用ledger/markerそのもの・runtime/cacheは収録しない。原本やprivate対応表を移動・上書きせず、匿名projectionだけを追加する。監査の適用範囲・失敗/再利用・未確認flagは省略しない。

保全済みの2026-11-03限定照合と2026-10-20の旧監査結果を区別して転記した。元rawを取得した第三者が全チェックを再実行できるとの保証ではない。母平均・数学的独立性・p8 export flag・原profile/回路の限界を保持する。

今回の許可は資料収録の範囲に限定する。新科学計算・数値再解析・sampling・compile、原SOURCEの変更、既存の科学的STOP解除は含まない。公開後はMANDATORY STOP。
